资源大升级：10 亿 Token、10 万张图

/ UPGRADE

微信AI小程序成长计划迎来重磅加码。通过云开发 CloudBase 开发的小程序，大模型 Token 额度从 1 亿提升至 10 亿，AI 生图额度从 1 万张提升至 10 万张；同时模型全面升级至混元最新模型 Hy3 与 Hy Image 3.0 生图模型。

10 亿 Token、10 万张图，意味着你可以放心地把 AI 能力「用厚」在产品里，不必再盯着用量条算账。资源包自申请成功之日起 6 个月有效。

模型全面升级至混元最新模型：Hy3 大语言模型 + Hy Image 3.0 生图模型，覆盖文本生成、图像生成两大核心 AI 场景。

02

全行业开放，立即报名

/ OPEN

报名依然全行业开放，延续此前承诺，好创意不被类目限制，全行业开发者皆可申请。

报名入口：微信公众平台 → 行业能力 → 小程序成长计划。没有云开发环境的可免费获得 6 个月个人版环境，已有环境的自动升级或领取 120 元代金券，均附赠 AI 资源包。

03

三步开始使用

/ GUIDE

开通 CloudBase 环境

访问 CloudBase 官网注册，创建首个个人版环境，同步报名微信 AI 小程序成长计划，Token 与生图额度自动到账。

启用大模型

进入 CloudBase 控制台 → AI → 生文模型，勾选 Hy3 preview 或其他所需模型，即刻可调用。

生成第一个小程序

使用微信开发者工具 → 云开发 → AI 助手，或通过 CloudBase MCP/Skill 在 AI 编程工具中用自然语言生成完整小程序代码，几分钟内完成部署。

常见问题

/ POSTSCRIPT

Q：在哪里查看 AI 资源包的用量？

小程序扫码登录 CloudBase Web 控制台，或最新版微信开发者工具的「云开发 → AI」模块可查。用量达 80%、90%、100% 时通过微信公众号消息提醒。

Q：AI 资源包用完后如何处理？

可切换为 CloudBase 资源点套餐，套餐内资源点直接抵扣大模型 Token 用量。详细规则参见 CloudBase 文档「接入大模型 - 资源点套餐」。

Q：怎么用自然语言开发小程序？

配置一次 CloudBase MCP/Skill（在 CodeBuddy、Cursor、Codex 等工具中填入 CloudBase Base URL 和 API Key），后续通过自然语言描述需求即可生成完整小程序代码并部署。

Q：小游戏开发者能用这些资源包吗？

可以。享受与小程序开发者同等的 CloudBase AI 资源包支持。入口：MP 后台 → 功能 → 游戏能力地图 → AI 成长计划。

Q：大模型 API Key 在哪获取？

CloudBase 控制台 → 环境配置 → API Key。Base URL 为 https://.api.tcloudbasegateway.com/v1/ai/cloudbase，兼容 OpenAI 协议。

Q：个体工商户能开发 AI 小程序吗？

可以。持有营业执照的个体工商户可申请添加「深度合成」类目，CloudBase 提供相应算法资质，配合微信官方文档提交即可。

报名入口：微信公众平台 → 行业能力 → 小程序成长计划
