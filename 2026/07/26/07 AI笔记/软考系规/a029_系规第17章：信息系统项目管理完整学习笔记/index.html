复习建议

学习目标

学习目标

项目管理不只是控制范围、进度和成本。新版知识体系以价值为最终导向：组织选择正确的项目，项目团队用适合情境的方法正确地做事，并把可交付成果转化为成果、收益和可持续价值。

这是“系规学习”的第14期。第17章把传统的过程组和十大知识领域，与项目管理原则、绩效域和价值交付系统放在一起。学习时要避免把这些框架混成一张表：原则指导行为，生命周期组织阶段，过程组组织管理活动，知识领域按专业分类，绩效域关注成果，价值系统连接战略。

01PART

本章地图：从“完成项目”到“实现价值”

LEARNING · KEY POINTS

项目是为创造独特产品、服务或成果而进行的临时性工作。临时性表示有明确起点和终点，不代表持续时间一定很短；项目结束后，其成果仍可能长期存在。

项目通过可交付成果达成目标，并推动组织从当前状态走向未来状态。价值既可能是货币、资产、市场份额等有形效益，也可能是声誉、品牌、公共利益、战略联盟等无形效益。

— 价值驱动项目管理全景

价值驱动知识体系包括：

●12项项目管理原则；

●项目生命周期和阶段；

●五大过程组；

●十大知识领域；

●八大项目绩效域；

●价值交付系统。

项目常由四类因素发起：法律法规或社会需要、干系人需求、创造改进修复产品过程服务、执行业务或技术战略。

02PART

17.1.1—17.1.4 项目基本要素：分清项目、项目集、项目组合和运营

LEARNING · KEY POINTS

项目何时结束

常见情形：

1项目目标已经达成；

2目标无法达成；

3资金耗尽或不再获得支持；

4项目需求不复存在；

5无法获得所需人力或物力；

6因法律或其他原因终止。

传统项目成功关注时间、成本、范围、质量，还应考虑客户满意、收益和价值是否实现。

四类管理对象

— 项目项目集项目组合关系

对象 定义与关注点 负责人 成功标准
项目 创造独特成果的临时性工作，关注项目内部依赖 项目经理 质量、进度、预算和客户满意
项目集 协调管理相互关联的项目、子项目集和活动，以获得单独管理得不到的效益 项目集经理 交付预期效益的能力、效率和效果
项目组合 为战略目标组合管理项目、项目集、子组合和运营 项目组合经理 总体投资效果和实现的效益
运营 持续生产产品或提供服务 运营经理 持续、稳定和高效运营

关键区别：

●项目集不是“大项目”，其核心是组成部分相互关联并协同实现收益；

●项目组合中各项目不必直接相关，核心是战略选择、优先级和资源分配；

●项目和项目集强调正确地做事，项目组合强调做正确的事；

●运营不属于项目管理范围，但项目与运营会在产品生命周期中交叉，如移交、上线和改进。

组织级项目管理将项目组合、项目集和项目管理整合到战略框架，确保选择正确工作并适当分配关键资源。

03PART

17.1.5—17.1.7 项目环境与组织：项目不是在真空中运行

LEARNING · KEY POINTS

组织过程资产与事业环境因素

组织过程资产是组织内部积累、可供项目选择和裁剪的帮助：

●过程资产：工具、方法论、模板、框架、PMO资源；

●治理文件：政策和流程；

●数据资产：历史项目数据库、度量和工件；

●知识资产：团队与专家的隐性知识；

●安保安全实践：设施访问、数据保护、保密和专有秘密程序。

事业环境因素是项目通常不能自行选择、需要适应的条件：

●内部：文化、结构、治理、资源地理分布、基础设施、信息技术软件、资源可用性和人员能力；

●外部：市场、社会文化、法律、商业数据库、学术研究、政府行业标准、财务和自然环境。

识别技巧：

●模板、经验库、变更控制程序通常是组织过程资产；

●项目管理信息系统、组织文化、结构和基础设施通常是事业环境因素；

●组织过程资产只来自组织内部，事业环境因素可来自内外部。

组织结构对项目的影响

从职能型、弱矩阵、均衡矩阵、强矩阵到项目导向型，项目经理权限、资源可用性和全职项目人员比例总体逐步提高。

●职能型：项目经理权限极少或无，预算由职能经理管理；

●弱矩阵：项目协调员兼职，权限低；

●均衡矩阵：项目经理和职能经理共享权力；

●强矩阵：项目经理全职，权限中到高，管理预算；

●项目导向型：项目经理权限和资源控制最高，团队多为全职；

●混合型：多种结构并存。

案例看到“项目经理全职、指定角色、控制预算、几乎所有工作需其批准”，更接近项目导向型，而不只是强矩阵。

三类PMO

1支持型：顾问和资源库，提供模板、培训与经验，控制程度低；

2控制型：要求采用指定方法、模板、工具和治理框架，控制程度中；

3指令型：直接管理控制项目，指定项目经理并要求其汇报，控制程度高。

PMO集中管理的项目不一定相互关联。它可作为重要干系人和关键决策者，提出建议、传递知识、终止项目。

项目管理与产品管理

产品是可量化生产的工件，也包括服务及其组件。产品生命周期可能包含项目集、单个项目，或在项目集中开展产品管理。项目有终点，产品管理通常持续关注市场、路线图、运营和全生命周期价值。

04PART

17.2 项目经理的角色：管理事情，也要领导人与价值

LEARNING · KEY POINTS

项目经理由执行组织委派，负责领导团队实现项目目标；职能经理管理专业职能，运营经理保证持续运营效率。

项目经理可能从项目启动前的可行性研究、论证、战略分析开始参与，也可能在项目完成后继续跟进收益和业务价值。

影响力范围

项目经理要：

●平衡相互冲突的干系人目标并促成共识；

●运用人际关系、沟通技能和积极态度；

●协调共享资源、资金优先级、交付发布和战略一致性；

●展现项目管理价值，提高组织接受度和PMO效率；

●与职能经理、运营经理、项目集与组合经理、专家和顾问协作；

●充当项目管理的宣传者。

三类关键能力

1项目管理能力：项目、项目集和组合相关知识、技能与行为；

2战略和商务能力：行业、组织和商业知识，保证成果支持战略；

3领导力：指导、激励并带领团队达成目标。

口诀：项目、商务、领导。

管理与领导力

管理 领导力
利用职位权力 利用关系指导、影响与合作
维护、控制、接受现状 建设、创新、挑战现状
关注系统、近期和可操作问题 关注人际、长期愿景和激励
正确地做事 做正确的事

项目经理必须同时管理和领导。关注范围并解决操作问题偏管理；激发信任、利用关系影响合作偏领导。

六种领导风格

1放任型：团队自主决策和设定目标；

2交易型：按目标、反馈和成绩给予奖励；

3服务型：服务优先，关注成员成长、学习、自主和福利；

4变革型：通过愿景、激励、创新和个别关怀提升追随者能力；

5魅力型：热情、自信、有说服力并激励他人；

6交互型：结合交易、变革和魅力特点。

根据里程碑完成情况奖励成员属于交易型，不是变革型。

05PART

17.3.1 十二项项目管理原则：所有方法之上的行动指南

LEARNING · KEY POINTS

1勤勉、尊重和关心他人：诚信可信、合规负责，并考虑财务、社会、技术和可持续影响；

2营造协作的项目团队环境：形成团队本地文化，促进学习发展和最佳贡献；

3促进干系人有效参与：主动互动、服务干系人并推进价值交付；

4聚焦于价值：价值是成功最终指标，持续评估并调整以最大化收益；

5识别、评估和响应系统交互：从整体理解内外部系统和相互依赖；

6展现领导力行为：领导力不等于职权，按情境调整风格并以身作则；

7根据环境进行裁剪：每个项目独特，应持续选择适合情境的方法；

8将质量融入过程和成果：既满足成果验收标准，也保证过程适当有效；

9驾驭复杂性：识别人、系统、不确定性和模糊性造成的复杂影响；

10优化风险应对：同时管理机会和威胁，考虑风险偏好、成本效益和责任人；

11拥抱适应性和韧性：应对变化、承受冲击并快速恢复，聚焦成果而非单项输出；

12为实现目标而驱动变革：用结构化方法推进状态转变，避免变革疲劳并争取干系人参与。

记忆主线：

先对人和团队负责（1—3），以价值和系统为方向（4—5），用领导与裁剪组织方法（6—7），管好质量、复杂性和风险（8—10），最后靠适应韧性推动变革（11—12）。

易错点：“勤勉负责”不是“展现领导力”；“每个项目具有独特性，应选独特方法”对应裁剪原则。

06PART

17.3.2—17.3.6 项目管理体系：阶段、过程、专业与成果如何配合

LEARNING · KEY POINTS

通用项目生命周期

项目从启动到完成经历一系列阶段，阶段可顺序、迭代或重叠。通用结构：

1启动项目；

2组织与准备；

3执行项目工作；

4结束项目。

成本和人力投入开始较低、执行期间最高、结束时回落；风险与不确定性开始最高并逐步降低；变更和纠错成本则随项目推进显著升高。

五类开发生命周期

— 五类项目生命周期

类型 核心特点 适用
预测型 前期确定范围时间成本，严格控制变更，阶段通常一次 需求明确、共识高
迭代型 重复循环开发，不断加深对产品理解并修改时间成本 需要逐步澄清方案
增量型 分次增加功能，最后一次后形成完整能力 希望分批交付功能
适应型 高频细化需求，短迭代交付价值，干系人持续反馈 需求不确定、变化快
混合型 对不同部分组合预测型和适应型 稳定与探索部分并存

迭代强调重复优化，增量强调逐步增加功能。适应型先做高层级计划，再把需求细化到当前规划周期。

五大过程组

1启动；

2规划；

3执行；

4监控；

5收尾。

过程组是管理过程的逻辑分组，不等于项目阶段。过程可以在每个阶段按需重复。规划过程组制定实现目标的计划；执行过程组完成计划中的工作，不能颠倒。

在适应型项目中，启动可在每次迭代开展；规划让更多成员和干系人参与；执行通过迭代指导工作；监控维护待办清单并调整；收尾优先完成最具业务价值工作。

十大知识领域

1整合管理；

2范围管理；

3进度管理；

4成本管理；

5质量管理；

6资源管理；

7沟通管理；

8风险管理；

9采购管理；

10干系人管理。

口诀：整、范、进、成、质、资、沟、风、采、干。

关键过程识别：

●启动：制定项目章程、识别干系人；

●规划：各知识领域的规划、需求范围WBS、活动进度、成本预算、风险识别分析应对等；

●执行：指导管理工作、管理知识质量沟通团队、获取资源、实施风险应对采购、管理干系人参与；

●监控：监控项目、整体变更、确认与控制范围，控制进度成本质量资源采购，监督沟通风险和干系人；

●收尾：结束项目或阶段。

八大项目绩效域

干系人、团队、开发方法和生命周期、规划、项目工作、交付、测量、不确定性。

绩效域是交付成果所需的相互关联、相互依赖的活动领域，在项目全程同时运行，不能当成依次执行的八个阶段。

价值交付系统

项目组合、项目集、项目、产品和运营可单独或共同创造价值。逻辑链：

战略与目标 → 项目等组件 → 可交付物 → 成果 → 收益 → 价值 → 反馈战略。

可交付物是项目产生的产品、服务或结果；成果是使用或转化后的结果；收益是组织获得的利益；价值是这些收益的重要性、实用性和贡献。

三门考试怎么用

综合题重点区分：项目/项目集/组合、资产/环境因素、组织结构和PMO、管理/领导、领导风格、12原则、生命周期、过程组/阶段、十大领域、八大绩效域。

案例题优先看组织和方法是否匹配：跨项目资源冲突用组合优先级与资源池；相互关联项目用项目集协调收益；需求高变却使用瀑布应改适应型或混合型；上线运维困难要加强项目与运营衔接；PMO类型按控制强度识别。

论文可将本章作为总框架：背景与价值目标—方法裁剪—团队干系人—生命周期与过程—知识领域措施—绩效测量—成果收益价值。不要机械罗列十大领域，要围绕真实问题说明方法和结果。
