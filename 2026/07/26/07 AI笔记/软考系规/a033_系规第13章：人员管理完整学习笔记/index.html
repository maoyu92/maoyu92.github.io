系规第13章：人员管理完整学习笔记

学习目标

人员管理不是“缺人就招、年底打分”，而是先把工作和岗位说清楚，再让战略决定供求计划，通过招聘获得合适的人、培训提升能力、绩效与薪酬引导行为，并用职业发展实现组织与员工的共同成长。

这是“系规学习”的第10期。第13章记忆项很多，但结构很稳定：定工作、设岗位、算供求、选人才、育能力、评绩效、配薪酬、促发展。本文按教材13.1—13.7完整展开，同时标出案例识别点和计算口径。

本章地图：人员管理是一条“人岗匹配”闭环

人力资源管理的四项目标

  1. 建立招聘与选择体系，获得最符合组织需要的员工
  2. 挖掘员工潜能，使其既服务组织目标，也满足个人事业发展
  3. 留住以绩效助力组织目标的员工，淘汰无法满足发展需要的员工
  4. 遵守人力资源相关法律、法规、政策和标准。

五项主要活动

活动 回答的问题
规划 要完成什么工作、设置什么岗位、需要多少人
招聘 从哪里找到人，怎样选出最合适的人
维护 怎样保持积极性，并提供安全健康的环境
提升 怎样提高知识、技能、经验和工作素养
评价 怎样观察、测量并改进员工和管理策略的结果

口诀：规、招、维、提、评。

一条贯穿全章的逻辑

战略提出人才要求 → 工作分析明确任务与任职特征 → 岗位设计组织工作 → 供求预测发现缺口 → 招聘录用补充人才 → 培训弥合能力差距 → 绩效反馈与薪酬激励引导行为 → 职业发展留住人才。

13.1—13.2 工作分析与岗位设计：先把“事”和“岗”说清楚

工作分析：分析工作，不是评价员工

工作分析的目的是明确两件事：

  1. 这项工作要完成哪些任务
  2. 完成任务的人应具备哪些能力特征。

它为招聘选择、培训发展、绩效评价、薪酬政策、组织与岗位设计提供基础。案例中出现“职责口头描述、任职资格不清、招聘筛不出人、培训内容脱岗、绩效没有标准”，通常都应先补工作分析。

工作分析四阶段十步骤

  1. 明确工作分析范围
  • 确立工作分析目的
  • 确定工作分析对象
  • 确定所需信息类型。
  1. 确定工作分析方法
  • 识别工作信息来源
  • 明确具体实施步骤。
  1. 收集和分析工作信息
  • 收集信息
  • 分析信息
  • 向组织报告结果
  • 定期检查工作分析情况。
  1. 评价工作分析方法
  • 按收益、成本、合规性和合法性评价结果。

案例必背：工作分析四个核心流程

  1. 明确工作分析对象
  2. 选择收集工作分析信息的人员
  3. 编制工作说明书
  4. 评价工作分析。

口诀：对、人、书、评。

选择信息收集人员时：

  • 关键、重要的工作，宜由工作分析专家实施
  • 新工作或变化较大的工作，宜由主管人员实施
  • 相对成熟稳定的工作，可由典型任职者实施。

工作说明书包括两个部分：

  • 工作描述：工作设定、工作定义、工作说明，回答“做什么”
  • 工作规范：资格要求、职业传统、胜任标准与特征，回答“什么样的人能做”。

评价工作分析要考察灵活性并权衡成本收益，还要区分：

  • 可靠性：不同分析者或不同时间分析同一工作，结果是否一致
  • 有效性：分析结果与实际工作是否准确吻合。

定性工作分析方法

方法 适用与优点 局限
工作实践法 亲自做，能准确了解任务及技能、环境要求；适合短期可掌握工作 不适合训练量大或危险工作
直接观察法 能较全面深入了解身体活动型工作，如装配、保安 不适合高脑力劳动或间歇性紧急工作
面谈法 快速、适用面广，能发现观察不到的问题 信息易失真，不宜作为唯一方法
问卷法 成本低、速度快、不影响工作，适合大量调查且便于量化 设计耗时，填写质量依赖配合程度
典型事例法 用具体行为揭示工作的动态性质 收集分类耗时，难代表通常行为

口诀：实、观、谈、问、例。

定量工作分析方法

  1. 职位分析问卷法：从使用程度、时间、重要性、发生可能性、适用性等方面进行6分制评分，系统但烦琐、时间成本高
  2. 管理岗位描述问卷法：围绕战略计划、协调、控制、责任、公共关系、咨询、自主权、审批权、人员服务、监督、压力等管理活动分析
  3. 功能性工作分析法：假设每项工作都体现为与数据、人、事三要素的关系，等级数值越小表示等级越高。

岗位设计：把工作组织成可执行岗位

岗位设计的目的是明确某类或某组工作的内容和方法，并协调技术、组织要求与员工社会、个人需要。

三个主要内容：

  1. 工作内容设计：岗位设计的重点，包括广度、深度、完整性、自主性、反馈性
  2. 工作职责设计：责任、权利、方法和相互沟通，尤其要做到权责相匹配
  3. 工作关系设计：岗位之间的协作关系和监督关系。

口诀：内容、职责、关系。

四种岗位设计方法

方法 核心思想 识别词
科学管理方法 把工作简化为最简单任务，在严密监督下提高效率 标准化、分工、低成本、高产出
人际关系方法 重视工作的心理影响和成就感、满足感等内在报酬 愉快、挑战、满足
工作特征模型 核心工作维度引发心理状态，进而影响动力、绩效和满意度 技能多样性、任务完整性、任务意义、自主性、反馈
高绩效工作系统 结合科学管理和人际关系，同时重视社会系统与最优技术安排 扁平化、网络化、社会技术结合

易错点：工作分析产生岗位信息，岗位设计决定怎样组合和组织工作；工作评价则比较岗位相对价值。三者不能混为一谈。

13.3 人力资源战略与计划：把战略翻译成人员供求

战略性人力资源管理

战略性人力资源管理强调人力资源管理与组织战略、各层级政策及一线日常实践相整合。它包括：

  1. 人力资源战略
  2. 人力资源管理系统。

管理过程包含两个相辅相成的阶段：战略制定确定文化、绩效、目标和战略方向；战略执行贯彻所选择的人力资源战略。

两组三种战略模式

第一组：戴尔和霍德分类。

战略 核心特征 案例识别
诱因战略 控制劳工成本、职责明确、竞争性薪酬、薪酬紧密联系绩效、关系简单 高薪换稳定，强调交易与结果
投资战略 重培训开发、人才储备、职责宽泛、长期雇佣、良好关系和宽松环境 成长期、多招人、多技能、长期培养
参与战略 权力下放，鼓励参与决策，管理者像教练，重自我管理和团队建设 授权基层、参与、创新

第二组：巴伦和克雷普斯分类。

战略 目标与特征
内部劳动力市场战略 维护组织独特知识，减少选拔培训成本；层级分明、内部招聘、工作保障与发展机会
高承诺战略 最大化产出和组织认同；扁平化、团队合作、薪酬体现成果差别
混合战略 兼有内部晋升和工作保障，同时采用基于成果的绩效与薪酬

人力资源需求预测

需求预测常考虑五类解释变量：

  1. 业务量
  2. 预期人员流动率
  3. 提质或进入新行业的决策
  4. 技术水平或管理方式变化
  5. 财务资源约束。

三种方法：

  • 集体预测法（德尔菲法）：综合专家意见形成一致判断，适合长期趋势
  • 回归分析法：依据历史变量关系预测，简单形式是趋势分析，复杂形式是计量模型
  • 转换比率分析法：先估计关键技能员工数量，再按比例推算辅助人员。

人力资源供给预测

需求预测只研究组织对人的需要；供给预测同时研究组织内部和外部能够提供多少人。

常用方法：

  1. 人才盘点与技能清单：组织岗位盘点 → 人才盘点 → 制定行动计划
  2. 管理人员置换图：记录绩效、晋升可能性和培训需要，用于重要职位补缺
  3. 人力接续计划：依据岗位要求确定可接任候选人
  4. 转移矩阵法（马尔可夫法）：利用过去人员流动规律预测未来分布
  5. 人力资源信息系统：收集、汇总和分析人员信息
  6. 外部人力资源供给分析：研究外部潜在员工的数量和能力。

供求结果与调节

  • 供求相等：保持并动态监测
  • 需求大于供给，人员短缺：增加录用，或提高人均生产率、延长工作时间
  • 供给大于需求，人员过剩：减少加班和工时、鼓励提前退休、减少招聘，或向合作伙伴输出闲置人力；没有其他选择时才辞退。

人力资源计划必须具有整体性：

  • 内部一致：招聘、选才、安置、培训、绩效考核相互配合
  • 外部一致：服从组织总体规划，并考虑业务进退、扩容、设备和信息系统变化。

整体计划包括三张表：供给报表、需求报表、人力报表。

评价时既要检查目标是否合理，也要将实际与计划比较，包括招聘数、工作效率、流动率、行动方案、实施结果、人力成本、方案成本及成本收益。人力资源审计重点检查管理活动是否按原计划执行。

13.4 招聘与录用：从发现缺口到验证招聘效果

招聘五步

  1. 制订招聘计划
  2. 发布招聘信息
  3. 应聘者申请
  4. 人员甄选与录用
  5. 招聘评估与反馈。

口诀：计、发、申、选、评。

招聘计划包括岗位与数量、岗位要求、发布时间方式渠道范围、对象来源范围、招聘方法、测试部门、预算、结束和到岗时间。用人部门制订，人力资源部门复核，主管领导审批，这个责任顺序常设陷阱。

招聘渠道

渠道 关键特点
内部来源 内部发布信息，利于晋升和组织知识延续
招聘广告 各类岗位均可使用，最普遍
职业介绍机构 帮助选拔、节省时间，适合无专门人事部门或急需补缺
猎头组织 搜寻高级主管和高级技术人员
校园招聘 专业技术人员的重要来源
员工推荐与自荐 节省广告费用，可能获得忠诚可靠员工
网络招聘 自建网站、第三方招聘网站、社交媒体
临时性雇员 内部储备、中介临时雇用、自由职业者、短期雇用

临时性雇员虽然灵活，但可能增加招聘和培训成本、降低质量稳定性，并要求加强管理激励。

录用方法与测试

主要筛选依据包括申请表、员工测评和录用面试。测试方法包括：

  • 能力测试
  • 操作能力与身体技能测试
  • 人格与兴趣测试
  • 成就测试
  • 工作样本法
  • 测谎、笔迹判定、体检等。

工作样本法测实际业务能力，而不是理论学习能力，可采用操作、口头表达或管理情景测试。

三种多元选择原则

  1. 补偿性原则：强项可补偿弱项，适合没有单项最低要求、强调综合素质的岗位；案例中的加权总分通常属于此类
  2. 多元最低限制原则：每项都必须达到最低标准，应先做低成本测试，把高成本测试放后面
  3. 混合原则：先以最低限制淘汰，再用补偿性原则综合排序。

面试类型与程序

程序：面试前准备 → 实施面试 → 评估结果。

  • 非结构化面试：自由讨论话题
  • 半结构化面试：准备重要问题但顺序可变，或按问题表结合岗位灵活追问
  • 结构化面试：预先设计固定问题及可能答案。

面试容易受到评价者情绪和主观偏差影响，因此应结合其他测评，统一标准并保留证据。

招聘效果五指标

  1. 招聘周期：完成一个职位招聘所需时间
  2. 用人部门满意度：用人部门对新员工的满意程度
  3. 招聘成功率＝实际上岗人数÷面试人数×100%
  4. 招聘达成率＝实际上岗人数÷计划招聘人数×100%
  5. 招聘成本：显性成本＋隐性成本。

易错点：成功率的分母是面试人数，达成率的分母是计划招聘人数。绩效考核结果还是检验招聘录用质量的最终反馈。

13.5 人员培训：从“上过课”走到“工作中会用”

培训四步骤

  1. 评估培训需求
  2. 设定培训目标
  3. 设计培训项目
  4. 实施并评估培训。

口诀：需、目、设、评。

两类培训

  • 入职培训：消除新员工焦虑，使其熟悉组织、适应环境
  • 在职培训：针对工作效果提升绩效，成本较低，且能迅速获得工作反馈。

新员工培训内容包括组织标准、行为规范、工作期望、传统政策，组织所期待的态度价值观，以及工作所需知识技能。

在职培训内容从三个层次分析：

  1. 组织分析：组织战略、资源和环境是否支持培训
  2. 绩效分析：实际绩效与期望绩效的差距是否由能力不足造成
  3. 任务分析：工作任务要求哪些知识、技能和行为。

即使当前绩效合格，也可能因岗位调动、晋升或工作内容变化产生前瞻性培训需求。

培训效果四层衡量

  1. 反应：受训者对课程是否满意、是否认为有用
  2. 学习效果：知识、技能、态度是否发生变化
  3. 行为变化：回到岗位后是否采用所学行为
  4. 培训效果：是否改善绩效和组织结果。

只调查“课程满意度”只测到了反应层，不能证明培训有效。

培训迁移

培训迁移关注知识、技能和态度能否真正转化为工作行为和结果。鲍德温—福特模型指出：

  • 输入：受训者特征、培训设计、工作环境
  • 中间结果：学习与保存
  • 最终结果：迁移与维持。

有利于迁移的工作环境具有六个特征：

  1. 主管鼓励应用新技能并设定目标
  2. 工作任务会提醒或要求应用新技能
  3. 能获得应用结果的反馈
  4. 初次应用出现失误时不轻易公开责难
  5. 成功应用能获得薪酬、绩效等外部强化
  6. 应用新技能能产生胜任感、成就感等内部强化。

案例整改可以写：让受训者与主管共同制定应用计划；重新设计工作任务；由主管持续观察辅导；允许合理试错；将应用结果接入绩效和奖励；对成功实践公开认可。

13.6—13.7 绩效、薪酬与职业发展：让贡献被看见、被改进

绩效管理四环闭环

  1. 绩效计划：在战略指导下由管理者与员工共同确定“做什么、如何做”；通常经历收集信息、确定关键工作领域与关键绩效指标、讨论确定计划
  2. 绩效实施与监控：贯穿全过程，持续沟通、记录、辅导和纠偏
  3. 绩效考核：全过程都需积累证据，周期结束集中评价，并结合员工自评和管理者考核
  4. 绩效反馈面谈：对结果达成共识，确认进步与不足，制定改进计划，并协商下一周期目标。

口诀：计、施、考、谈。

绩效管理不是年底一次打分，更不是只用来发奖金。没有事前目标、过程记录、反馈改进，就没有形成闭环。

五类绩效考核方法

方法 如何识别
员工比较类评价法 简单排序、成对比较、强制分布，核心是人与人比较
关键事件法 记录特别有效或特别无效的典型工作行为
行为对照表法 将员工行为与预设行为陈述逐项对照
等级鉴定法 先定评价标准，每个项目列出若干等级行为供选择
行为锚定评价法 明确定义评价维度，并用关键事件描述各绩效等级

简单排序易操作，但难说明差距原因，也不能自动提供具体改进建议。

绩效改进三步

  1. 分析考核结果，找出绩效问题
  2. 针对问题制定可实施的改进方案，如个性化培训
  3. 在下一阶段辅导中执行方案，提供知识和技能支持。

绩效改进连接本轮考核与下一轮计划，是绩效管理能否真正发挥作用的关键。

薪酬体系

员工获得的报酬包括：

  • 外在薪酬：货币和可计量福利
  • 内在薪酬：工作保障、身份、挑战性工作、晋升、认可、培训、弹性时间、良好办公条件等。

外在薪酬可进一步分为：

  • 直接报酬：基本薪酬、奖金佣金等绩效加酬、延期支付
  • 间接报酬：保险等保护项目、假日病假等非工作报酬、交通餐饮等服务津贴。

工作评价：确定岗位相对价值

工作评价比较工作的任务责任、所需技能及其对组织目标的相对贡献，以工作分析信息为基础。

五种常用方法：工作排序法、因素比较法、工作分类法、点数法、海氏系统法。

两种分类角度：

分类角度 方法
整体、非量化 工作排序法、工作分类法
按要素、量化 因素比较法、点数法、海氏系统法
工作之间相互比较 工作排序法、因素比较法
与既定标准比较 工作分类法、点数法、海氏系统法

记忆矩阵：排—因是横向比，分—点—海对标准；排—分看整体，因—点—海拆要素。

薪酬等级与分类激励

薪酬等级结构五要素：等级数、目标薪酬、级差、幅度、重叠情况。

针对不同对象的激励：

  • 操作人员：常用计件制
  • 销售人员：佣金制或底薪制
  • 专业人员：常用加薪
  • 高级管理人员：基本薪酬、短期奖金、长期奖励、普通福利、特殊福利或津贴；长期激励常用股票。

薪酬调整

按性质：

  • 主动型调整
  • 被动型调整。

按内容：

  • 奖励性调整
  • 生活指数性调整
  • 年资性调整
  • 效益性调整。

按结构：

  • 纵向调整：增加或减少薪酬等级
  • 横向调整：改变固定与浮动薪酬比例，或调整不同薪酬形式组合。

案例中“绩效好就调薪”属于奖励性调整；“所有人只按工龄涨薪”容易造成贡献和薪酬脱节。

职业规划与管理

职业规划把个人兴趣、能力、价值取向和发展目标，与组织岗位通道、培养资源和人才需要相匹配。管理上应形成：

  1. 员工自我评估
  2. 组织提供真实岗位与发展信息
  3. 共同确定阶段目标和发展路径
  4. 通过培训、轮岗、导师、晋升等行动实施
  5. 根据员工变化和组织战略定期复盘调整。

它不是承诺每个人都晋升，而是让员工看见成长路径，也让组织提前形成关键岗位人才梯队。

三门考试怎么用

综合题重点区分：工作分析方法、岗位设计方法、两组战略模式、需求与供给预测、三种录用原则、招聘五指标、培训四层效果、绩效考核方法、工作评价矩阵和薪酬调整类型。

案例题先沿闭环找缺项：没有工作说明书 → 补工作分析；职责混乱 → 重做岗位设计；人力短缺无预测 → 做供求计划；只凭一次面试 → 组合测评；培训脱岗且无跟踪 → 需求分析＋四层评估＋迁移环境；年底主观打分 → 绩效四环＋客观证据；一刀切薪酬 → 工作评价＋绩效薪酬＋分类激励。

论文可按“背景与人员问题—工作岗位梳理—供求预测与招聘—能力培养—绩效薪酬—职业发展—成效与改进”组织。重点写清自己如何参与、采用什么方法、形成什么成果及数据变化。

  1. 人力资源管理的五项活动是什么？

  8. 培训四步骤、四层效果和六项迁移环境特征是什么？

写在最后

第13章看似清单繁多，真正的骨架只有一句话：

先用工作分析和岗位设计定义“需要怎样的人”，再用供求预测、招聘和培训解决“人从哪里来、能力怎样长”，最后用绩效、薪酬和职业发展回答“怎样用好并留住人”。

第一轮先默写：对人书评、内容职责关系、需供调节、计发申选评、需目设评、计施考谈。第二轮再补方法对比、指标公式和案例整改，整章就能从零散名词变成可调用的管理闭环。
