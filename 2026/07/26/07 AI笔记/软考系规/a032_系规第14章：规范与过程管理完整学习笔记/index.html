学习目标

学习目标

规范解决“用什么共同规则做”，流程解决“跨岗位怎样协同做”。真正的过程管理不是画完流程图，而是从战略和业务对象出发规划流程，用制度、责任和系统保障执行，再通过稽查、绩效、满意度和审计推动持续改进。

这是“系规学习”的第11期。第14章的主线很清楚：标准化 → 流程规划 → 流程执行 → 流程评价 → 持续改进。综合题重概念和清单，案例题常考规划方法、执行找茬、评价方法识别和优化步骤。

01PART

本章地图：规范是基线，流程是路径，评价是闭环

LEARNING · KEY POINTS

标准化对象包括需要反复使用并制定标准的产品、定额、规划、要求、方法和概念等，可分为：

●具体对象：需要制定标准的具体事物；

●总体对象：具体对象共同构成的整体，用于研究共同属性、本质和规律。

标准化管理强调按PDCA开展计划、实施运行、检查纠正和管理评审，并持续提高标准水平。

— 规范与过程管理闭环

全章一句话：

用标准化减少无效差异 → 用端到端视角搭建流程框架 → 明确责任并固化执行 → 用多种评价发现差距 → 将问题、绩效和变革需求转化为下一轮优化。

02PART

14.1 管理标准化：不是“一刀切”，而是有度统一

LEARNING · KEY POINTS

八项标准化基本原理

1超前预防原理：不仅处理已经重复的问题，也从潜在重复问题中选择对象，预防不必要的多样化和复杂化；

2系统优化原理：优先标准化能获得效益的问题，局部效益服从主体系统的全局最佳效益；

3协商一致原理：标准成果建立在相关方协商一致基础上，如公开征求意见；

4统一有度原理：统一是核心，但单一化不等于标准化；统一要有范围、层次、水平和量度；

5动变有序原理：标准随环境变化，按规定时间和程序修订审批；

6互换兼容原理：产品、服务或过程应能互换，且共同使用时不产生不可接受干扰；

7阶梯发展原理：标准化是逐级提高的长期过程，标准制定只是开始；

8阻滞即废原理：标准既能促进也可能阻碍发展，必须复审并作更改、修订、废止或确认。

口诀：超、系、协、统、动、互、阶、阻。

易错点：

●标准通常以推荐、自愿执行为原则，法律法规具有强制性；但被法规、合同引用后可能产生约束；

●国际、国家、行业和地方标准通常规定5年有效期，组织标准一般3年；

●到期不是一律废止，而是根据复审结果作更改、修订、废止或确认。

简化

简化不是任意删减，而是调整事物构成并使其最优化：

1压缩不必要的多样化，同时防止过度压缩；

2论证必须明确时间和空间范围；

3在既定时间内满足一般需要，不能损害用户利益；

4产品简化应形成系列，参数组合尽量符合标准数值分级。

系列化

系列化是按规定数系，对同类产品的参数同时标准化，目的在于简化品种规格并满足多方面需要。

三个方面：

1制定产品参数系列：首要环节，也是型谱和系列设计的基础；

2编制产品系列型谱：用图表表达基型、变型及品种发展趋势，确定后不宜轻易改变；

3开展产品系列设计：选基型 → 设计基型 → 横向扩展规格 → 纵向扩展变型。

组合化和模块化

●分解：把可通用、互换的功能单元分离为标准模块或通用模块；

●组合：把标准、通用和专用模块按新系统要求组合成新功能系统。

组合化是分解与组合的统一，统一化单元可拆装、重组和重复利用。案例中“沉淀公共基础模块，按产品需求挑选组合”就是组合化和模块化。

综合标准化

综合标准化把系统工程与标准化结合，以对象系统为研究对象，协调相关要素，使整体功能效果最佳。其物质基础是相互协调的标准综合体，包括产品标准综合体和一般技术性标准综合体。

七项要求：

1把对象及相关要素作为系统；

2范围明确且相对完整；

3全过程有计划、有组织；

4以技术、经济、社会整体效益最佳为目标；

5低层次服从高层次；

6充分采用现行标准，必要时修订补充；

7综合体内各标准制定与实施相互配合。

超前标准化

超前标准化依据预测，对未来可能成为最佳的对象，规定高于现实水平的规格和要求，是动态标准化的体现。

三个阶段：准备 → 制定超前标准 → 贯彻超前标准。

超前指标可分阶段、按不同日期实施。预测对象包括科技水平、需求量、生态指标和经济指标。识别题看到“高于当前实际水平”“预测未来最佳要求”，选超前标准化；不要与超前预防原理混淆，后者强调提前选择潜在重复问题。

03PART

14.2 流程规划：从端到端的“线”扩展为组织的“面”

LEARNING · KEY POINTS

端到端流程

端到端流程从获取业务对象需求开始，到业务对象满意结束，强调：

●以终为始、目标导向；

●从目的而不是局部任务出发；

●以战略为导向进行全局和系统管理；

●追求整体最优，而不是部门或个人局部最优。

流程规划不是推倒重来，也不是一步到位，而是对现有体系持续、系统地完善。从端到端流程到组织整体框架，是流程从“线”到“面”的优化：既要让流程与战略匹配，也要让流程间协同运行。

组织最高管理层是流程框架总图的责任人，负责制定并传达战略。前期策划一般由流程管理部门完成；流程规划小组至少包括高级管理层、流程管理部门人员、相关部门负责人。

两种流程规划方法

— 两种流程规划方法对比

基于岗位职责：从下到上

1确定各部门代表性岗位；

2与代表性岗位访谈；

3分解主要工作并评价重要度；

4梳理工作中的流程和关键控制点；

5访谈部门负责人，补充完善；

6汇总流程信息，完成流程清单和流程框架。

优点：分析细致、不易遗漏；流程部门主导，对受访者专业要求不高；干系人参与充分，成果易接受。缺点：工作量大，质量受受访者经验和表达能力影响。

基于业务模型：从上到下

1根据组织业务绘制简易业务模型；

2分解模型；

3与干系人把模型和现有流程关联对接；

4对无法对接部分访谈代表岗位；

5完成流程清单和流程总图。

优点：工作量较小，流程部门控制力强，进度风险易控。缺点：可能遗漏，对参与者专业能力要求高，基层参与不足可能影响认可。

三类流程

1战略流程：面向未来，规划和分解战略目标，制定策略、竞争模式并控制调整；

2运行流程：直接为业务对象创造价值，包括产品价值链、市场链、供应链、服务链，逻辑为战略 → 业务模式 → 运行流程；

3支持流程：提供决策、后勤和风险控制支持，以战略为导向、以支持运行流程为目的。

支持流程不直接为业务对象创造价值，但会影响运行流程的效率和效果。

三级流程

●一级流程：高阶“域”，往往是端到端流程；

●二级流程：中阶“域过程”；

●三级流程：低阶具体流程，由子流程和业务活动构成。

同一起终点还可按业务对象、风险、输入、重要度、业务模式或管理对象划分不同操作线路。

04PART

14.3 流程执行：把图上的流程变成组织行为

LEARNING · KEY POINTS

八项执行保障：

1理解流程：既理解做法规则，也理解原因、目的、原则、岗位价值和违规后果；

2变更后推广：关键流程变化后及时培训和交流，避免多版本并行；

3新员工培训：利用入职黄金期讲流程制度并塑造行为习惯；

4找对负责人：流程管理者对整体结果、设计、推动、检查和优化负责；流程助手参与执行并掌握实时状态；

5流程审计及监控：用稽查、评价和违规处理保证执行；

6固化到信息系统：提高透明度、共享、自动化和知识积累；

7固化到制度：明确关键规则和绩效激励，形成组织约束；

8流程文化宣导：让员工习惯从流程视角做事。

口诀：理解、推广、入职、责任、监控、系统、制度、文化。

案例常见问题及整改：

●只发文档、不培训 → 解释目的规则，开展入职和变更培训；

●变更后版本不一致 → 统一发布、回收旧版、培训确认；

●责任推诿 → 明确流程管理者与流程助手；

●执行不可见 → 建立监控稽查并固化到信息系统；

●有流程无约束 → 纳入制度、绩效和文化宣导。

“固化到系统”不等于僵化。信息化前应先保证流程合理，并保留例外、授权和变更机制。

05PART

14.4 流程评价：四种方法解决四类问题

LEARNING · KEY POINTS

流程评价承上优化设计、对下保障执行，是流程闭环最重要的环节。

四类检查方法

方法 对象与问题 典型输出
流程稽查 单个流程是否按制度执行、执行是否到位 具体不符合项和整改
流程绩效评估 流程结果是否达到目标 指标差距、趋势和改进方向
满意度评估 业务对象需求和体验是否得到满足 需求、不满、建议及综合结论
流程审计 整个流程体系是否充分、适用、有效、有效率 体系级评估与改进建议

易错点：稽查单个流程，审计整个体系；绩效看目标结果，满意度看业务对象感受。

流程稽查七步

1理解流程目的、目标及管理原则；

2确定影响目标达成的关键控制点；

3确定查资料、现场观察、访谈等方法；

4设计稽查线路和实施计划；

5开展稽查，并说明改进目的；

6提交具有普遍性、重大性、代表性问题的报告；

7跟进整改，重点评估严重度并分析根因。

绩效评估三个维度

●效果：产出在多大程度上满足业务对象需求和期望；

●效率：实现效果时节约资源、减少浪费的程度，指标如处理时间、投入产出比、增值时间比例、质量成本；

●弹性：动态调整以适应当前和未来需求的能力，典型指标是适应性。

战略导向指标体系：战略目标按平衡计分卡和SMART分解 → 一级流程目标 → 可管理级流程目标 → 指标体系。

结果分析四角度：

1与绩效目标纵向对比；

2组织内部横向对比；

3与同行竞争者标杆对比；

4分析结果稳定性。

稳定但未达理想水平，应优化流程设计；数据持续波动说明过程失控，应先加强质量控制。

满意度信息六来源

日常沟通、投诉抱怨、走访、电话回访、满意度问卷、满意度评估信息库。问卷只是补充，不能替代日常真实信息的持续汇总。

流程审计十一步

制订计划 → 确定范围 → 初步调研 → 编制检查表 → 制订实施计划 → 首次会议 → 现场审计 → 补充审计 → 编制报告 → 末次会议 → 改进追踪。

改进追踪决定审计能否产生价值；只出报告、不闭环整改，审计没有完成管理目的。

评价结果五种应用

1流程优化；

2绩效考核；

3过程控制；

4纠正措施；

5战略调整。

过程控制是立即扭转不符合并恢复结果；纠正措施针对系统性或反复问题分析根因，防止再发。

06PART

14.5 持续改进：让流程随战略和需求一起进化

LEARNING · KEY POINTS

三类改进驱动

1问题导向：优化建议、流程事件、内外部投诉、意见、审计报告；

2绩效导向：流程目标、绩效测量、标杆比较；

3变革导向：组织战略、运营策略、重大改革、流程规划。

优化目标从两处找：一是组织战略要实现什么，二是组织当前要解决什么问题。

总体优化顺序

流程框架体系优化 → 具体流程优化 → 流程标准化 → 流程评价 → 未达目标则再次优化。

先优化框架，明确业务模式、资源配置、职能及问题边界；再优化具体流程解决重要问题；最后把成熟流程、规范、标准和知识沉淀到制度、执行标准和作业手册。

— 项目化流程优化六步

项目化六步：

1立项；

2现状分析及诊断；

3目标流程及配套方案设计；

4IT方案设计与开发；

5新旧流程切换；

6项目关闭。

评价不是终点，而是验证优化目标。如果未达到预设效果，应重新进入优化活动。

三门考试怎么用

综合题重点记：八项基本原理、五类标准化形式、两种规划方法、三类三级流程、八项执行措施、四类评价方法、绩效三维度、审计十一步、三类改进驱动。

案例题先判断题目所处阶段。规划遗漏看方法和干系人；执行不力补培训、责任、监控、系统和制度；评价单一补绩效、满意度和体系审计；改进无结果补目标、根因、标准化和再次评价。

论文可按“标准化背景—端到端流程框架—规划方法—执行保障—评价体系—优化项目—成效与反思”展开。正文不要只列流程图，应写清跨部门问题怎样发现、责任怎样落实、指标怎样变化。

SUMMARY · REVIEW SMARTER

第14章最重要的不是记住多少“流程术语”，而是建立这套管理闭环：

标准化提供共同规则，端到端规划消除部门割裂，执行机制把规则变成行动，评价用证据发现差距，持续改进再把有效做法沉淀为新标准。

第一轮先默写：超系协统动互阶阻、战运支、理解推广入职责任监控系统制度文化、稽绩满审、问题绩效变革。第二轮再补规划步骤、稽查审计和案例整改。
