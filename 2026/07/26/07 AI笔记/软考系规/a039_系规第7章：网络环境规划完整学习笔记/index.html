系规第7章：网络环境规划完整学习笔记

学习目标

第7章的技术名词很多，但主线并不乱：先认识网络的框架和协议，再分别规划广域网、局域网、无线网，最后补齐管理、安全、机房、布线、监控和节能。本文按教材7.1—7.5逐节展开，目标是读完即可完成本章第一轮系统学习。

这是“系规学习”的第4期。本章是综合题的技术高频章，也是案例题的重要来源。学习时不必把自己变成网络工程师，但必须能够识别关键协议、说清三类网络各自的规划重点，并能用管理和安全清单分析案例。

本章地图：一套基础，三类网络，一组保障

第7章可以压缩成“1＋3＋1”：

  1. 7.1 网络架构和主要技术：建立共同语言，包括五个平台、OSI七层、TCP/IP、传输平台和拓扑。
  2. 7.2 广域网规划：解决跨地区、跨管理域的连接和承载。
  3. 7.3 局域网规划：解决园区或组织内部的交换、VLAN、路由和地址分配。
  4. 7.4 无线网规划：解决频率、覆盖、容量、站址和无线组网。
  5. 7.5 网络整体规划重点事项：用网管、安全、机房、布线、监控和节能保障网络长期运行。

网络规划到底在规划什么

网络环境规划要根据客户的网络、业务和管理现状，综合考虑业务演进、财务状况、维护能力、建设步骤、设备折旧和技术趋势，完成：

  • 网络架构和覆盖范围规划
  • 技术、设备与组网方式选择
  • 承载能力与业务适应性规划
  • 网络安全、管理维护和配套环境设计
  • 原有网络演进、业务迁移与容灾备份安排。

最终目标是在客户人、财、物预算范围内，选择性价比较高的架构、技术和设备，做到因地制宜、适度超前，同时满足当前和可预见的未来需求。

三门考试先抓什么

  • 综合题抓OSI七层、TCP/IP、IPv4/IPv6、拓扑、VLAN、5G三场景、网络管理五功能。
  • 案例题抓广域网六项、局域网五个特有重点、无线网五项，以及网管、安全管理清单。
  • 论文可用“现状与需求—总体架构—三类网络—管理安全—迁移实施—持续优化”组织网络规划实践。

7.1 网络架构和主要技术：先建立共同语言

7.1.1 信息网络系统的五个平台

复杂网络通常用两种方式抽象：一是按业务功能模块划分，二是用网络信息流的七层协议模型抽象。按功能模块划分时，一个相对完整的信息网络系统包括五个平台：

平台 主要职责 典型内容
网络传输平台 高效、准确、安全地传输数据 传输、路由、交换、有线与无线接入
网络和应用服务平台 处理网络服务、管理逻辑、业务逻辑和数据 DNS、地址分配、OA、Web、邮件、会议等
安全服务平台 保护网络、应用和用户 加解密、防火墙、入侵检测、漏洞扫描、审计、证书
网络管理和维护平台 管理、监测和维护整个网络 网管、告警、性能、配置；对外运营时还需运营系统
环境系统 提供能源、空间、安防和物理连接 机房、环境监控、智能安防、节能、综合布线

记忆骨架：传、应、安、管、环。注意“网络和应用服务平台”与“网络管理和维护平台”不是一回事：前者支撑业务，后者保障网络运行。

7.1.2 OSI七层：不仅会背顺序，还要会定位

OSI模型自下而上是：

  1. 物理层：规定机械、电气、功能和规程特性，传输比特。
  2. 数据链路层：在相邻节点间成帧传输，进行差错检测和介质访问控制。
  3. 网络层：负责逻辑寻址和路由选择，传输数据包。
  4. 传输层：提供端到端传输，处理可靠性、顺序、拥塞和连接。
  5. 会话层：建立、管理和终止应用之间的会话。
  6. 表示层：处理数据表示、格式转换、压缩和加解密。
  7. 应用层：直接为用户应用提供网络服务。

自下而上的口诀可记为：物、链、网、传、会、表、应；培训资料常用“物联网传回试用”帮助回忆，但答题必须写规范层名。

TCP/IP四层与常见协议

教材采用四层结构：

  • 网络接口层：对应OSI物理层和数据链路层，典型协议ARP、RARP。
  • 网络层：对应OSI网络层，典型协议IP、ICMP、IGMP。
  • 传输层：对应OSI传输层及部分会话功能，典型协议TCP、UDP。
  • 应用层：综合OSI会话、表示、应用层功能，典型协议HTTP、Telnet、FTP、SMTP、DNS等。

TCP与UDP对比

对比项 TCP UDP
连接 面向连接，传输前建立连接 无连接，直接发送
可靠性 提供确认、重传、顺序控制 不保证到达与顺序
开销 较大 较小
适用 对可靠性要求高的业务 实时性优先、可容忍少量丢包的业务

考试中看到“可靠、有序、面向连接”选TCP；看到“无连接、时延低、开销小”优先考虑UDP。

IPv4、IPv6和路由

  • IPv4地址长度为32位，地址空间有限。
  • IPv6地址长度为128位，扩展地址空间并改进报文与自动配置能力。
  • ARP用于由IP地址解析MAC地址；ICMP用于差错报告和网络诊断。
  • 静态路由由管理员手工配置，结构简单、可控，但适应变化能力弱。
  • 动态路由能交换路由信息并随链路变化调整。教材将RIP、BGP列入距离矢量类，将OSPF、IS-IS列入链路状态类；应试时以教材表述为准。

传输平台的四类内容

网络传输平台一般由以下内容组成：

  1. 传输媒介：有线的光纤、双绞线、同轴电缆；无线的长波、中波、短波、超短波、微波等。
  2. 网络传输技术：SDH、PDH、DWDM、HFC、Wi-Fi、数字微波、卫星通信、移动通信等。
  3. 路由、交换和组网技术：路由侧重跨网络寻址，交换侧重一定范围内基于MAC转发；SDN把控制功能从传统设备中分离并集中控制转发。
  4. 有线、无线接入技术：PON、EPON、GPON、10G-PON，以及Wi-Fi、蓝牙等。

六种常见拓扑

常见网络拓扑包括总线型、星型、环型、树型、网状和复合型。规划时要在安全、可靠的基础上，尽量降低费用、减少时延、提高链路利用率；网络设计原则之一是使交换设备与传输链路总费用尽可能小。

  • 总线型结构简单、成本低，但主干故障影响大。
  • 星型便于管理和扩展，但中心节点是关键点。
  • 环型路径规则，可做保护，但节点或链路处理较复杂。
  • 树型适合分层组织，但上层节点影响范围较大。
  • 网状冗余和可靠性高，成本与管理复杂度也高。
  • 实际大型网络多采用分层的复合型拓扑。

7.2 广域网规划：解决跨地域承载

广域网是跨地区、省市乃至国家的大规模网络，用来连接局域网、城域网、省网等，可分为运营商广域网和企业/行业广域网。

7.2.1 广域网的一般架构

典型运营商网络通常包含全国骨干网、省级骨干网、城域网和接入网。IP城域网常采用三层架构：

层次 主要职责
核心层 提供高速骨干转发和出口连接，承载IDC、CDN等中心节点
汇聚层 汇聚区域业务，上联核心、下接接入设备
接入层 面向园区、楼宇、家庭和个人用户提供有线或无线接入

企业网也可采用核心—汇聚—接入的分层思想。中小型网络可以简化层级，但不能因此忽略出口冗余、安全域和可扩展性。

7.2.2 广域网主要技术

广域网技术主要围绕TCP/IP、多协议标签交换MPLS、虚拟专用网VPN、IP城域网、专线及各种接入技术展开。选型时应关注：

  • 业务带宽、时延、抖动、丢包和可用性
  • 多分支互联、互联网出口和云接入需求
  • 专线建设或租用成本
  • 路由收敛、链路冗余和故障切换
  • 与原有网络、运营商及云平台接口兼容性。

7.2.3 广域网规划六项必背

  1. 建设背景：为什么建，是新建、扩容、升级还是多网整合。
  2. 需求分析：用户规模、业务类型、流量流向、性能、安全和管理需求。
  3. 项目预算：设备、线路建设或租用、配套设施、实施、运维和优化成本。
  4. 技术方向：功能、性能、成熟度、接口、演进方向和维护能力。
  5. 网络拓扑结构设计：同时设计物理网络和逻辑网络，大型广域网通常分层并采用复合拓扑。
  6. IP地址等逻辑资源规划：统筹IPv4、IPv6、自治系统号、路由、域名等资源。

记忆骨架：背、需、预、技、拓、址。案例中出现“只买设备、没有流量预测”“没有考虑线路租费”“缺少IPv6地址规划”“单链路无冗余”，都可以对应到这六项指出缺失。

7.3 局域网规划：重点不只在交换机

局域网覆盖范围相对有限，常见于企业、园区、校园和楼宇。它通常采用以太网交换技术，并通过路由器或三层交换设备连接不同子网及外部网络。

7.3.1 一般架构与主要技术

大型园区局域网常采用核心、汇聚、接入三层架构；规模较小时可采用核心/汇聚合一的两层架构。主要技术包括以太网交换、VLAN、三层路由、生成树、链路聚合、DHCP、无线接入和网络准入等。

7.3.2 VLAN六种划分方法

方法 特点
按端口划分 配置简单、适合各种规模；用户换端口后通常需重新配置
按MAC地址划分 用户移动后成员身份可保持；初始化配置量大，较适合小型网络
按网络层协议划分 可按IP、IPX等协议组织；检查网络层信息带来额外开销
按IP组播划分 把一个IP组播组视为一个VLAN，灵活但效率不高
按策略划分 可组合端口、MAC、IP、协议等条件，适应管理策略
按用户定义、非用户授权划分 按特定用户要求定义，非成员需认证后加入

口诀：端、MAC、协、组、策、用。VLAN的本质是划分广播域和安全域，规划时应结合业务特性、地理位置与安全要求，而不是为了“看起来整齐”随意切分。

7.3.3 局域网五个特有重点

局域网同样要做建设背景、需求、预算、技术、拓扑、地址、安全、网管、机房和布线设计，但还要重点关注：

  1. VLAN划分：按业务、位置和安全要求决定划分方式。
  2. VLAN编号：统一编码并预留扩展空间，便于管理和排障。
  3. VLAN间路由设计：明确哪些VLAN允许互访、通过何处路由、如何实施访问控制。
  4. STP设计：在逻辑上发现并阻断二层环路，避免广播风暴；同时规划根桥和冗余链路。
  5. DHCP设计：规划地址池、租期、网关、DNS、中继、保留地址和容灾。

注意：VLAN ID的协议字段是12位，可用编号范围常表述为1—4094；教材正文写“1—4096”。遇到以教材原句设问的考试，以教程表述为准；实际工程配置则应遵循设备和标准的可用范围。

案例分析的常见问题

  • 网络扁平、广播域过大，没有按业务或安全域划分VLAN
  • 核心、汇聚或出口存在单点故障
  • 二层存在环路，却未规划STP或根桥位置
  • VLAN间全部互通，没有最小权限访问控制
  • DHCP地址池太小、没有中继或没有冗余
  • IP地址临时分配、冲突严重、未预留扩展空间
  • 只考虑带宽，没有考虑时延、丢包、终端增长和运维监控。

7.4 无线网规划：频率、覆盖与容量必须一起算

教材中的无线网包括三类：

  1. 运营商4G、5G移动通信网
  2. NB-IoT等面向特定场景的专用无线网
  3. Wi-Fi等无线局域网。

7.4.1 4G与5G

  1. G采用OFDM、软件无线电、智能天线、MIMO和基于IP的核心网等技术。5G进一步面向三类典型场景：
场景 中文 典型需求与应用
eMBB 增强移动宽带 大带宽、高速率；高清视频、AR/VR等
uRLLC 超高可靠低时延通信 极低时延、高可靠；工业控制、远程医疗、自动驾驶
mMTC 海量机器类通信 大规模连接、低功耗；智慧城市、智能家居、环境监测

口诀：大带宽、低时延、海量连。5G核心网采用服务化、微服务思想，并通过网络切片支持不同场景的差异化能力。

7.4.2 NB-IoT与无线局域网

NB-IoT面向低功耗广域物联网，适合海量、低速率、低功耗、覆盖要求较高的终端。Wi-Fi适合局部区域高速无线接入，规划时需考虑标准版本、频段、信道、干扰、接入密度、漫游、认证和有线回传。

不要只看到“无线”就默认Wi-Fi：远距离、低功耗、大量传感终端可能更适合NB-IoT；极高可靠低时延业务可能面向5G专网；办公室和园区高吞吐接入通常重点规划Wi-Fi。

7.4.3 无线网五项必背

无线网除一般网络规划内容外，还要重点关注：

  1. 无线频率规划：频率是有限、排他的资源，要降低干扰、提高利用效率。
  2. 无线传输覆盖范围规划：结合建筑、地形、穿透和抗干扰特性消除覆盖盲区。
  3. 无线传输容量规划：根据用户规模、业务特征和业务量预测容量，不能只保证“有信号”。
  4. 无线基站站址规划：兼顾覆盖、容量、回传、电源、机房、物业和施工条件。
  5. 无线组网规划：设计基站、控制、核心网、回传与其他网络的连接关系及冗余。

记忆骨架：频、覆、容、址、组。

覆盖与容量为什么不能混为一谈

覆盖回答“能不能收到信号”，容量回答“多人同时使用时能不能满足业务”。增加发射功率可能扩大覆盖，却不一定增加系统容量；单纯增加接入点也可能导致同频干扰。实际规划需要通过现场勘察、预测模型、容量估算和测试优化形成闭环。

7.5 整体重点：网络建成以后能否管好、守住、持续运行

7.5.1 网络管理五大功能

国际标准化组织定义的网络管理五大功能是：

  1. 故障管理：采集告警，判断、定位并支持故障恢复。
  2. 配置管理：配置网络服务，采集和管理设备配置，使网络整体运行最优。
  3. 性能管理：采集、分析性能数据，掌握网络和设备运行状况。
  4. 计费管理：记录网络资源使用情况，控制和监测费用与代价。
  5. 安全管理：提供设备与网络管理层面的安全功能，保障网络安全运行。

口诀：故、配、性、计、安。网络管理系统自下而上分为网元/网络层、管理应用层、表示层：底层提供受管对象和数据，中层实现管理功能，上层提供人机界面。

7.5.2 网络安全设计与安全管理

网络安全设计关注四项：

  • 网络结构：结构及安全域划分是否合理
  • 访问控制：边界设备、访问规则和控制粒度是否合理
  • 网络入侵防护：能否监测和防御拒绝服务、扫描、蠕虫等攻击
  • 网络安全审计：能否对设备、流量和用户行为统一记录与分析。

典型手段包括防火墙、VLAN安全域、IDS/IPS、统一日志和SOC。

安全管理另有五项必背：

  1. 安全组织和责任
  2. 风险管理工作机制
  3. 应急处理工作机制
  4. 容灾备份工作机制
  5. 系统上线、切换办法及安全运维方案。

要分清“安全设计关注点”和“安全管理机制”：前者偏技术控制，后者偏组织、流程与持续运行。

7.5.3 机房、布线、监控和节能

机房建设七项

机房建设包括机房装修、空调系统、电气系统、接地和防雷系统、消防系统、环境监控系统、节能降耗系统。它是建筑、空调、给排水、强弱电、消防和装饰等多专业协同的工程。

综合布线三层构成

综合布线把网络、电话、监控、电源、照明等线路按标准、统一、结构化方式规划。基本构成包括：

  • 建筑群子系统
  • 干线子系统
  • 配线子系统。

设计时要综合考虑建筑性质、业务带宽、线缆距离、终端类型、发展需求、价格和安装条件，并与网络、安全防范和建筑设备监控同步规划。

机房监控五类子系统

  1. 机房动力环境系统监测
  2. 机房网络设备监控
  3. 机房门禁监控
  4. 机房环境消防监控
  5. 统一运维管理平台。

节能降耗

从选址、密封绝热、配风和气流组织、冷热通道、设备能效、动态制冷及智能分析等方面降低能耗。节能不是竣工后的附加优化，而应在规划阶段纳入方案。

三门考试怎么用

综合题

优先默写并识别：

  • 五个平台：传、应、安、管、环
  • OSI七层与TCP/IP四层
  • 六种拓扑、VLAN六种划分
  • 广域网六项、局域网五项、无线网五项
  • 5G三场景
  • 网管五功能、安全设计四重点、安全管理五机制。

案例题

答“网络规划存在什么问题”时，可按以下顺序扫描材料：

  1. 是否调查建设背景、用户、业务、流量和管理需求
  2. 是否设计分层拓扑、冗余链路、地址和容量
  3. 局域网是否规划VLAN、路由、STP、DHCP
  4. 无线网是否兼顾频率、覆盖、容量、站址和干扰
  5. 是否具备故障、配置、性能、计费和安全管理能力
  6. 是否补齐安全域、边界控制、入侵防护、审计、容灾和应急
  7. 是否考虑机房、布线、监控、节能、迁移和持续优化。

写答案时使用“问题＋后果＋改进”的句式。例如：核心出口采用单设备单链路，存在单点故障，可能导致全网业务中断；应采用设备与链路冗余，并验证故障切换机制。

论文

可按“背景与目标—现状调研—总体分层架构—广域/局域/无线方案—管理与安全—机房与配套—迁移实施—监控优化”展开。论文中不要堆协议名，要说明每个选择解决了什么业务问题、如何控制风险、如何验证效果。

闭卷自测

  1. 信息网络系统五个平台分别是什么？
  2. OSI七层与TCP/IP四层如何对应？TCP和UDP有何区别？
  3. 六种常见拓扑是什么？
  4. 广域网规划六项主要内容是什么？
  5. VLAN六种划分方法和局域网五个特有重点是什么？
  6. G三类场景分别面向什么需求？
  7. 无线网五项重点是什么？
  8. 网络管理五大功能及三层体系结构是什么？
  9. 网络安全设计四项关注点和安全管理五项机制是什么？
  10. 机房建设、综合布线和机房监控分别包括什么？

写在最后

第7章看似全是协议和设备，真正的学习骨架其实是：

五个平台＋两套分层模型＋三类网络＋一组运行保障。

第一轮先把广域网六项、局域网五项、无线网五项和网管五功能默写出来；第二轮再补OSI协议、VLAN、5G、机房和安全细节。做案例时始终回到“需求是否清楚、架构是否合理、容量是否够、运行能否管、安全能否守、故障能否恢复”六个问题。
