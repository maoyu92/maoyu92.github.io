坐着写代码out了：HiTerm 让你用手机语音遥控 AI 编程

手机语音输入指令的速度明显快于打字，远程开发不受座位限制，APP 和 PC 无缝切换——HiTerm 解决了一个很多人实际存在却很少被认真解决的痛点。

一、问题的本质

Claude Code、Codex、Gemini CLI 这类 AI 编程工具很强，但有一个天然的局限：你必须守在电脑前才能监控它们运行。

开始一个任务后只能干等着？出门买杯咖啡不知道任务跑完没有？出差路上想看看 CI 构建到哪一步了？传统方案是你得带着电脑，或者靠粗糙的截图通知——体验割裂，信息有限。

HiTerm 解决的就是这个问题：让手机成为你 PC 终端的延伸，随时随地实时监控和操控。

二、HiTerm 是什么

一句话定位：

一个免费的开源远程终端，让你的手机和 PC 实时同步，支持任意 AI 编程 Agent。

核心使用场景：

  • 手机上实时监控 Claude Code / Codex / Gemini CLI 的运行状态

  • 不在电脑前时也能输入指令、查看输出

  • 外出时远程调试生产服务器

  • 多台机器的 tmux 会话统一从手机管理

三、核心特性

实时双向同步

PC 终端上显示什么，手机上同步显示什么。手机上的操作也会实时回传到 PC 终端。所有数据走 P2P 直连，不经过第三方服务器。

支持所有主流 AI 编程 Agent

只要跑在终端里的 AI 工具都能用，不限于某一家的产品：

  • Claude Code

  • Codex

  • Gemini CLI

  • Cursor

  • Windsurf

  • Aider

  • 以及任何基于终端的 AI 工具

断线不丢会话

基于 tmux，会话持久化。即使手机断连、切换网络、甚至 PC 重启，会话状态全部保留。重新连接后无缝继续。

P2P 加密传输

通过 Tailscale（基于 WireGuard）建立端到端加密隧道，不走任何中继服务器。Tailscale 个人使用免费。

手机语音输入

这就是用户描述的”手机语音输入指令的速度要明显快于打字”——手机系统原生语音输入直接进入终端，打字速度问题瞬间解决。

mosh 协议支持

弱网环境也能保持连接，信号波动不中断。外出在地铁上也能稳定连上公司机器。

四、技术架构

组件 技术选型
PC 端 CLI Go
Android 端 Java（Termux 分支）
网络隧道 Tailscale（P2P，WireGuard 加密）
会话管理 tmux（持久化）+ mosh（弱网优化）

架构示意：

手机（Hi Term App） ↓ Tailscale P2P 加密隧道 PC（hiterm CLI + tmux） ↓ AI Coding Agent（Claude Code / Codex / Gemini CLI...）

所有数据不过中继服务器，只经过 Tailscale 的 P2P 隧道直连。

五、三分钟快速上手

第一步：安装 Tailscale（两台设备都要装）

下载：https://tailscale.com/download[1]

两台设备登录同一个账号，自动建立加密隧道。

第二步：安装 hiterm CLI（PC 端）

curl -fsSL https://hiterm.yinbin.ink/install.sh | bash

第三步：安装 Hi Term App（Android）

下载地址：https://hiterm.yinbin.ink/download/[2]

第四步：配对设备

hiterm pair

手机 Hi Term App 扫描 PC 上显示的二维码，完成配对。

第五步：开始使用

手机打开 Hi Term，选择要连接的 PC 和 tmux 会话，即可开始操作。

六、典型使用场景

场景 1：监控 AI 编程

早上到公司，启动 Claude Code 跑一个复杂的重构任务。中间去开会、去茶水间，手机上实时看到任务进度。Code 完成时手机收到通知，不用专门跑回工位盯着。

场景 2：外出时远程调试

出差路上收到告警，登录手机上的 Hi Term，SSH 跳板机，查看日志、重启服务、定位问题——全程手机操作，不需要开电脑。

场景 3：多机器统一管理

公司服务器、个人开发机、测试机……多台机器的 tmux 会话全部汇聚到手机，一个 App 切换管理，不再需要记一堆 SSH 配置。

场景 4：语音输入写代码片段

手机自带的语音输入比打字快，语音说一段命令或脚本，比在手机键盘上一点点敲要高效得多。对于简单的指令修改和查看，语音输入完全够用。

七、和同类方案对比

工具 核心差异 限制
HiTerm 专门针对 AI Agent 场景优化，P2P 加密，免费，tmux 原生 目前主要 Android 端
TeleClaude Web 浏览器访问，多客户端实时共享同一会话 无移动端 App，依赖浏览器
Claude Code Remote Tailscale + 脚本，灵活但需要手动配置 无专用 UI，需要自己搭
yazinsai/claude-code-remote 专注于 Claude Code 的远程访问 功能相对单一

HiTerm 的核心差异化：免费 + 专用 Android App + P2P 直连不过服务器 + 专门为 AI Agent 场景设计。

八、关于免费

官网明确声明：

Hi Term is 100% free with no ads, no tracking, and no premium tier. The CLI tool, Android app, and all features are completely free.

Tailscale 个人使用也是免费的。整个方案零成本。

九、局限和注意事项

  • 目前主要支持 Android：iOS 端暂无专用 App

  • 需要两台设备（PC + 手机）：不适合单设备场景

  • Tailscale 需要公网可达：部分内网环境需要额外配置 DERP 中继

  • 不是全功能的远程桌面：只有终端，没有图形界面
