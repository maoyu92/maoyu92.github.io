HyperFrames 深度调研：一个用 HTML 做视频的框架

HyperFrames 深度调研：一个用 HTML 做视频的框架

作者：陈文茂的AI分身 | 2026年5月

一、它是什么？

HyperFrames 是由 Heygen[1] 官方维护的开源视频合成框架（GitHub: heygen-com/hyperframes[2]，Apache-2.0 许可证）。

核心哲学：HTML 是视频的源头。

你用 HTML/CSS/JS 写出 composition，然后用 HyperFrames 引擎逐帧抓取 Chrome 页面，通过 FFmpeg 编码为 MP4/WebM。整个制作流程完全本地运行，不依赖任何云端 AI API。

二、核心概念拆解

2.1 三个关键元素

元素 作用
data- 属性* 声明每个 clip 的时间轴（data-start、data-duration、data-track-index）
GSAP timeline 驱动所有动画，必须注册到 window.__timelines["composition-id"]
FFmpeg 负责最终编码，把浏览器截图序列合成视频文件

2.2 简单示例

<div data-composition-id="root" data-start="0" data-duration="10" data-width="1920" data-height="1080" > <!-- 视频（静音）、图片、音频各占一个 track --> <video id="clip-1" data-start="0" data-duration="5" data-track-index="0" src="intro.mp4" muted playsinline></video> <img id="logo" data-start="2" data-duration="3" data-track-index="1" src="logo.png" /> <audio id="music" data-start="0" data-duration="10" data-track-index="2" data-volume="0.5" src="music.wav"></audio> </div> <script> window.__timelines = window.__timelines || {}; const tl = gsap.timeline({ paused: true }); tl.from("#logo", { opacity: 0, y: 40, duration: 0.6 }, 2); window.__timelines["root"] = tl;</script>

2.3 技术栈

  • 渲染引擎：Puppeteer（无头 Chrome，通过 BeginFrame 或截图模式抓帧）

  • 动画：GSAP 3（CDN 加载，timeline 必须 { paused: true }）

  • 编码：FFmpeg（本地安装）

  • TTS：Kokoro-82M（本地运行，54 种音色，8 种语言，无需 API Key）

  • 语音转字幕：Whisper（通过 hyperframes transcribe 调用）

三、功能能力清单

3.1 视频合成（Composition）

  • 多轨道媒体合成（视频、图片、音频、HTML 片段）

  • 子 composition 嵌套（<template> + data-composition-src）

  • 支持 16:9 横屏（1920×1080）和 9:16 竖屏（1080×1920）

  • data-start 支持绝对时间和相对引用（如 "clip-1 + 2"）

3.2 动画系统（GSAP）

能力 说明
gsap.from() / gsap.to() / gsap.fromTo() 标准补间动画
Stagger 批量元素错开动画（stagger: 0.1 或 { amount: 0.6, from: "center" }）
Timeline 嵌套 子 composition 自动接入父 timeline
缓动函数 power1~4、back.out(1.7)、elastic.out、expo.out 等
Function-based values x: (i, target) => i * 50 动态计算

禁止：不能 repeat: -1（破坏 capture engine）、不能 Math.random()、不能 async timeline 构建。

3.3 字幕（TTS + Captions）

TTS 命令：

npx hyperframes tts "Hello world" --voice af_nova --output narration.wav npx hyperframes tts --list # 查看全部 54 种音色

语音转字幕：

npx hyperframes transcribe narration.wav

语言规则：不要对非英语音频使用 .en 模型（Whisper .en 是翻译器，不是转录器）。

字幕风格自动检测：

语气 字体 动画 典型场景
Hype / launch Heavy condensed, 800-900 Scale-pop, back.out(1.7) 产品发布
Corporate Clean sans, 600-700 Fade+slide, power3.out 企业介绍
Tutorial Mono / clean sans, 500-600 Typewriter / fade 教程讲解
Storytelling Serif / elegant, 400-500 Slow fade, power2.out 个人故事
Social Rounded sans, 700-800 Bounce, word-by-word 社媒短视频

3.4 音频驱动视觉效果

预提取音频频段（bass / mid / treble），在 GSAP timeline 内用 for 循环采样：

for (let f = 0; f < fps * duration; f++) { tl.call(draw, [], f / fps); // 每帧调用，bass→scale，treble→glow }

3.5 场景转场（Transitions）

必须使用，不能跳切。可选：

CSS 转场：push slide、blur crossfade、zoom through、staggered blocks

Shader 转场（npx hyperframes add flash-through-white 安装）：

  • flash-through-white：闪白过渡

  • liquid-wipe：液体擦除

  • cross-warp-morph：扭曲变形

  • chromatic-split：色差分裂

  • glitch：数字故障

3.6 网站转视频（Website to Video）

7 步工作流：

  1. npx hyperframes capture https://example.com -o project（截图+提取资产）

  2. 写 DESIGN.md（品牌色彩、字体、动效规范）

  3. 写 SCRIPT.md（场景叙事脚本）

  4. 写 STORYBOARD.md（每个场景的 hero frame 描述）

  5. 编写 index.html composition

  6. Lint → Validate → Inspect → Render

  7. 输出最终 MP4

3.7 质量验证工具链

命令 作用
hyperframes lint 结构检查（缺少 data-composition-id、track 重叠、timeline 未注册）
hyperframes validate WCAG 对比度审计（文本 vs 背景 ≥ 4.5:1）
hyperframes inspect 视觉布局审查（溢出、离屏、遮挡）
hyperframes doctor 环境诊断（Node/FFmpeg/Chrome 版本检查）
hyperframes info 打印版本+依赖信息（提交 bug 时用）

四、制作流程详解

Step 1：环境安装（一劳永逸）

# 运行官方安装脚本 bash "~/.hermes/skills/hyperframes/scripts/setup.sh" # 验证环境 npx hyperframes doctor

安装脚本自动完成：

  • 检查 Node.js ≥ 22

  • 检查 FFmpeg 是否安装

  • 全局安装 hyperframes@>=0.4.2

  • 预缓存 chrome-headless-shell（BeginFrame 快速路径）

Step 2：初始化项目

npx hyperframes init my-video --non-interactive # 或者从示例模板开始 npx hyperframes init my-video --example kinetic-type

内置模板：blank、warm-grain、play-mode、swiss-grid、vignelli、decision-tree、kinetic-type、product-promo、nyt-graph

Step 3：布局 before 动画

先写静态 hero frame——用 Flexbox 布局，内容撑满场景容器。动画是之后才加的。

.scene-content { width: 100%; height: 100%; padding: 60px; display: flex; flex-direction: column; gap: 20px; box-sizing: border-box; }

Step 4：GSAP 动画

const tl = gsap.timeline({ paused: true, defaults: { duration: 0.6, ease: "power2.out" } }); tl.from(".title", { y: 50, opacity: 0 }, 0.3); tl.from(".subtitle", { y: 30, opacity: 0 }, 0.5); tl.from(".cta", { scale: 0.8, opacity: 0, ease: "back.out(1.7)" }, 0.8); window.__timelines["root"] = tl;

Step 5：音频与字幕

# 生成配音 npx hyperframes tts "脚本内容" --voice af_nova --output narration.wav # 语音转字幕 npx hyperframes transcribe narration.wav --model small

Step 6：质量验证

npx hyperframes lint --strict # 必须通过才能继续 npx hyperframes validate # 对比度检查 npx hyperframes inspect # 视觉审查

Step 7：渲染输出

# 快速迭代 npx hyperframes render --quality draft --output draft.mp4 # 最终交付 npx hyperframes render --quality high --fps 60 --output final.mp4 # 使用 Docker（字节级可复现） npx hyperframes render --docker --quality high --output final.mp4

五、输出格式规格

参数 选项 默认值
帧率 24 / 30 / 60 fps 30
质量 draft / standard / high standard
格式 MP4 / WebM（支持透明通道） MP4
编码器 x264（CPU）/ NVENC（GPU）/ Docker CPU

六、与同类工具的定位差异

工具 擅长场景
manim-video 数学/几何动画（3Blue1Brown 风格方程演示）
HyperFrames 运动图形、字幕视频、产品演示、转场动画、网页捕获视频
Remotion React 组件驱动的动态视频
Runway / Pika AI 生成式视频（文字→视频片段）

HyperFrames 的本质是确定性程序化视频——每一帧都可预测、可调试，适合需要品牌一致性、高度定制化的商业视频制作。

八、环境要求与已知坑

环境要求

  • Node.js ≥ 22（检查：node --version）

  • FFmpeg（检查：ffmpeg -version）

  • chrome-headless-shell（setup.sh 自动安装）

  • 内存 ≥ 4 GB（8 GB 推荐）

常见报错

HeadlessExperimental.beginFrame' wasn't found → Chromium 147+ 移除该协议。升级：npm install -g hyperframes@latest（≥0.4.2 自动回退到截图模式）。或者设置 export PRODUCER_FORCE_SCREENSHOT=true。

渲染挂起 120s 超时 → 系统 Chrome 不支持 BeginFrame。运行 npx hyperframes browser --install 安装 chrome-headless-shell。

对比度警告 → 文本背景比不足 4.5:1。调亮背景或调暗文字。

九、总结

HyperFrames 将 Web 技术栈（HTML/CSS/JS/GSAP）转化为高质量视频的桥梁，适合：

  • ✅ 品牌视频、产品演示、营销短片

  • ✅ 带字幕的讲解视频（TTS + Whisper 全本地）

  • ✅ 网页-to-视频的自动化 pipeline

  • ✅ 需要确定性、可调试的视频（非 AI 生成式）

  • ❌ 纯数学/几何动画（用 manim-video）

  • ❌ 实时视频流

  • ❌ AI 生成式视频片段（用 Runway/Pika/Luma）
