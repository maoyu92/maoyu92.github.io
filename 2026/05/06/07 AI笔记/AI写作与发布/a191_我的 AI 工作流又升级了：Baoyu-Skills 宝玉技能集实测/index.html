我的 AI 工作流又升级了：Baoyu-Skills 宝玉技能集实测

今天花了大半天深度研究了 Baoyu-Skills 这个 Claude Code 技能集，发现它可能是目前最完整的中文内容创作工具链。

为什么花这么长时间研究它？

因为我一直在找一套真正能用的”从写作到发布”全链路工具。之前试过很多方案，要么配图要手动处理，要么排版适配公众号很麻烦，要么发布环节根本打不通。

Baoyu-Skills 把这些问题都封成了可单独调用的技能，而且零代码——只要告诉它要什么，它就帮你做完。

核心感受

最实用的三个技能：

  1. baoyu-article-illustrator — 写完文章自动识别配图位置，生成风格一致的插图。这个解决了图文消息最大的痛点。

  2. baoyu-format-markdown — 自动补全标题层级、加粗、列表，直接适配公众号格式。排版从此不再是体力活。

  3. baoyu-cover-image — 五维定制封面图生成系统，专业水准的封面图几秒钟出。今天用它做了一张 Warp Terminal 的封面（就是题图）。

安装情况

我是通过 OpenClaw 的 ClawHub 安装的，按需装了 6 个核心技能：

  • baoyu-format-markdown

  • baoyu-article-illustrator

  • baoyu-cover-image

  • baoyu-post-to-wechat

  • baoyu-infographic

  • baoyu-comic

全部通过 clawhub install 命令安装，MIT 协议，开源透明。

结论

值得接入，但建议按需安装，不要一次性装全套。先试排版 + 配图，满意了再逐步加入其他环节。

题图： 今天测试 baoyu-cover-image 生成的 Warp Terminal 封面，用的是商汤的 sensenova-u1-fast 模型。
