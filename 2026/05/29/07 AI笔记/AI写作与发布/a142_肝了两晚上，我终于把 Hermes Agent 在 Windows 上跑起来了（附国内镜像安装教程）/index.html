肝了两晚上，我终于把 Hermes Agent 在 Windows 上跑起来了（附国内镜像安装教程）

“AI 助手装好了，但每次都要手动启动、开着终端、还不能后台运行——这不是助手，这是祖宗。”

前情

大概一周前，我决定在 Windows 上跑一个 AI 助手框架，叫 Hermes Agent。

官网文档写得挺清楚，但实际装下来发现：国内网络环境有几个坑，原文没写；飞书机器人配置那块步骤也比较碎，不一次性踩完根本不知道下一脚踩哪。

网上搜到的教程要么是给 Mac/Linux 的，要么就是抄的官网没有实战细节。

所以我决定把这两天晚上踩的坑、走的弯路、最后跑通的全流程整理出来，给想装但还没装的同学省点时间。

一、先搞清楚你需不需要 Hermes

Hermes 是一个 Windows 本地运行的 AI Agent 框架，核心能力：

  • 支持接入多种大模型（MiniMax、OpenAI、Claude 等）

  • 内置飞书/钉钉/Discord 机器人，可以把 AI 助手直接搬到 IM 里

  • 技能系统，支持安装社区技能包扩展能力

  • 本地运行，数据不出本地

适合人群：

  • 想在本地跑一个可后台运行的 AI 助手

  • 想把 AI 助手接入公司飞书/钉钉

  • 对 OpenClaw 等工具感兴趣，想先试试水

不适合：

  • 完全不会命令行（装完还是要用 PowerShell）

  • 网络能裸连 GitHub（国内直接装会报错）

二、国内镜像一键安装（Windows PowerShell）

这是最关键的一步。不要用官网给的命令，直接用国内镜像，否则大概率卡在某个依赖下载上。

第一步：打开 PowerShell

按下 Win 键，搜索「Windows PowerShell」，直接打开，不需要管理员权限。

第二步：执行镜像安装命令

复制下面这条命令，粘贴到 PowerShell 里，按回车：

irm https://res1.hermesagent.org.cn/install.ps1 | iex

然后就是等。全程自动执行，大约 5-10 分钟，看网速。

安装脚本会自动检测并补装：Python 3.11、Node.js、Git 等运行环境，以及配置环境变量。

**看到提示 ✓ Hermes Agent 核心安装已经完成**，第一步就结束了。

三、初始化配置向导

这部分是整个流程最核心的环节。安装完成后会自动弹出配置向导，跟着一步一步走就行。

第一步：OpenClaw 配置迁移（如有旧环境）

如果你的电脑之前装过 OpenClaw，会提示迁移配置，直接选 Y 预览、再选 y 执行迁移就行。旧配置、密钥、技能库会自动导入，冲突文件会跳过，不会覆盖已有的东西。

第二步：选择快速配置

How would you like to set up Hermes? (●) 1. Quick setup — provider, model & messaging (recommended) (○) 2. Full setup — configure everything

直接回车，选快速配置就行。

第三步：选大模型服务商

以 MiniMax 国内版为例：

  1. 列表找到 26. MiniMax China (domestic direct API)，输入 26 回车

  2. 输入你的 API Key，回车保存

  3. 选模型，输入 3 回车，选用 MiniMax-M2.7

第四步：飞书机器人配置（重点）

这是大家问得最多的部分。

  1. Connect a messaging platform? → 直接回车，选择现在配置

  2. 输入 9 回车，选 9. 🪽 Feishu / Lark 飞书

  3. 直接回车，用扫码自动创建机器人（推荐）：

(●) 1. Scan QR code to create a new bot automatically (recommended)

  1. 复制页面给出的链接，用手机飞书扫码授权绑定

后面两个设置直接回车默认就好：

  • 私信权限：陌生人需要你手动审批（推荐）

  • 群聊规则：只有被 @ 时才回复

第五步：配置开机自启

这是让机器人”真正像助手”的关键一步。

按顺序确认：

  1. Install the gateway as a Scheduled Task service? → 输入 Y 回车

  2. Start the gateway now after install? → 输入 Y 回车（立即启动）

  3. Start the gateway automatically on Windows login? → 输入 Y 回车（开机自动启动）

  4. Open the UAC prompt now? → 输入 y 回车，弹出 Windows 账户控制，点击”是”授权

全部完成会出现 ✓ Setup complete!。

四、装完必做的两件事

第一件：重启终端（必须做）

关掉当前 PowerShell，重新打开一个。目的是让环境变量生效。

第二件：验证装好了

hermes --version # 看版本号 hermes gateway # 启动飞书网关（机器人核心服务） hermes doctor # 检查运行状态&故障诊断

如果 hermes gateway 能正常启动，说明机器人已经在后台跑着了。

五、常见问题

Q：PowerShell 提示脚本被阻止运行

以管理员身份打开 PowerShell，执行：

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

输入 Y 确认即可。

Q：hermes 命令找不到

环境变量没生效。彻底关闭所有终端，重新打开 PowerShell 即可。

Q：飞书机器人收不到消息

手动启动网关服务：

hermes gateway

检查飞书授权是否正常，必要时重新执行 hermes setup gateway 配置。

六、装好之后能做什么

飞书内直接对话：在飞书搜索你的机器人名称，发送消息即可对话。

设置通知会话：在飞书私聊窗口发送 /sethome，自动将当前会话设为通知窗口，机器人的定时任务和提醒会发到这里。

扩展技能：执行 hermes setup tools 补充 API 密钥（如生图、联网搜索），解锁更多能力。
