安装 nodejs

安装 git

# 安装 Git sudo yum install git -y # 安装最新版 Node.js sudo yum install -y nodejs # 验证安装结果 git --version node -v npm -v

安装 opencode

装这个是为了预防 openclaw 出错，可以用它解决，或者用来编程，免费的模型不用白不用

npm i -g opencode-ai

安装 openclaw

npm install -g openclaw@latest

升级 nodejs

npm install -g n n latest hash -r node -v
