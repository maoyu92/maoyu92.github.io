宝玉Skills深度调研：1.9万星的AI Agent技能包，到底值不值得装？

“

如果你用 Claude Code、Cursor 或 Codex，一定听说过「Skills」——给 AI 编程助手装上特定能力的「技能包」。宝玉（JimLiu）的 baoyu-skills 是目前最受欢迎的技能集之一，1.9 万 Stars。今天我们来深度拆解：这些技能到底能干什么？哪些值得装？

一、宝玉是谁？

宝玉（@Jimmy_JimLiu）是 AI 领域知名博主，长期分享 AI Agent 实践经验。他的 baoyu-skills 仓库不是「玩具级 Demo」，而是他自己每天在用的工作流技能包——从写公众号、做 PPT、生成封面图到小红书配图，全部由 AI Agent 自动完成。

GitHub 数据：

  • ⭐ 19,227 Stars

  • 🍴 2,241 Forks

  • 📅 创建时间：2026 年 1 月

  • 🌐 语言：TypeScript

  • 📦 安装方式：npx skills add jimliu/baoyu-skills

二、三大类技能全景图

宝玉的技能分为三大类：内容生成、AI 生成、工具技能。我们逐一拆解。

MEDIA:./imgs/baoyu-skills-overview.png

第一类：内容生成技能

这类技能帮你把内容变成可发布的格式——公众号、小红书、PPT、幻灯片。

baoyu-xhs-images（小红书图片卡片）

把一篇文章拆解成 1-10 张卡通风格的图片卡片，适合小红书、微博等平台。

核心能力：

  • 12 种视觉风格：cute（可爱）、fresh（清新）、warm（暖色）、bold（大胆）、minimal（极简）、retro（复古）、pop（波普）、notion（Notion风）、chalkboard（黑板）、study-notes（学习笔记）、screen-print（丝网印刷）、sketch-notes（手绘笔记）

  • 6 种信息布局：sparse（1-2 点，适合封面）、balanced（3-4 点，常规内容）、dense（5-8 点，知识卡片）、list（4-7 项，清单）、comparison（双栏对比）、flow（3-6 步，流程）

  • 3 种配色覆盖：macaron（马卡龙）、warm（暖色）、neon（霓虹）

使用示例：

/baoyu-xhs-images 文章.md --style notion --layout dense

baoyu-diagram（SVG 图表）

从源素材生成可直接发布的 SVG 图表——流程图、时序图、架构图、示意图、类图。

特点：

  • 不是调用图片生成模型，而是 Claude 直接手写 SVG 代码

  • 内嵌样式，自动支持深色/浅色模式

  • 一次确认后批量生成

baoyu-cover-image（封面图）

5 维度系统生成文章封面图：Type × Palette × Rendering × Text × Mood。

  • 6 种类型：hero、conceptual、typography、metaphor、scene、minimal

  • 11 种配色：warm、elegant、cool、dark、earth、vivid、pastel、mono、retro、duotone、macaron

  • 7 种渲染：flat-vector、hand-drawn、painterly、digital、pixel、chalk、screen-print

baoyu-slide-deck（幻灯片）

从内容生成专业幻灯片图片，适合快速出演示文稿。

第二类：AI 生成技能

baoyu-imagine（AI 生图）

统一的图片生成接口，支持多个后端模型。

baoyu-markdown-to-html（Markdown 转 HTML）

将 Markdown 内容转换为精美的 HTML 页面，适合博客、文档发布。

第三类：工具技能

baoyu-post-to-wechat（发布到微信公众号）

自动将文章发布到微信公众号草稿箱，与内容生成技能配合使用。

baoyu-format-markdown（Markdown 格式化）

Markdown 内容的格式化和优化工具。

三、实际工作流示例

宝玉的技能设计思路是链式工作流——一个技能的输出可以作为另一个技能的输入：

示例：从选题到发布全自动

1. 深度调研选题 → 生成 Markdown 文章 2. /baoyu-cover-image → 生成封面图 3. /baoyu-infographic → 生成内容信息图 4. /baoyu-diagram → 生成架构图/流程图 5. /baoyu-post-to-wechat → 发布到公众号草稿箱

整个流程只需要一条命令链，AI Agent 自动完成所有步骤。

宝玉 Skills 的独特优势：它是目前唯一一个专门为中文内容创作者设计的技能包——小红书卡片、公众号发布、中文信息图，这些是其他技能包不具备的。

五、安装方式

方式一：npx 一行命令（推荐）

npx skills add jimliu/baoyu-skills

方式二：OpenClaw 安装

clawhub install baoyu-imagine clawhub install baoyu-markdown-to-html # 或者告诉 Agent 请帮我安装 github.com/JimLiu/baoyu-skills 中的 Skills

方式三：Claude Code 插件市场

/plugin marketplace add JimLiu/baoyu-skills

六、适用场景

✅ 特别适合：

  • 微信公众号运营者（封面图+配图+发布一条龙）

  • 小红书/微博内容创作者

  • 需要频繁制作 PPT/幻灯片的人

  • 技术博客作者（SVG 图表+信息图）

  • 中文内容创作者

⚠️ 不太适合：

  • 纯代码开发、不需要内容输出的场景

  • 只用英文、不需要中文排版的用户

七、社区评价

宝玉 Skills 在知乎、Twitter 上获得了广泛好评：

“

“宝玉老师的 Skills 是我见过的最实用的 AI Agent 技能包，没有之一。” “信息图技能太强了，21 种布局随便选，比手绘快 100 倍。” “小红书卡片技能帮我节省了 80% 的排版时间。”

总结

宝玉 Skills 不是「技术炫技」的产物，而是一个真正解决实际工作流问题的技能包。它的核心价值在于：

  1. 中文优先：专门为中文内容创作者设计

  2. 全链路覆盖：从调研到发布，一条命令搞定

  3. 高度可定制：风格×布局×配色，组合出无限可能

  4. 持续更新：社区活跃，作者每天在用

如果你是中文内容创作者，这可能是目前最值得安装的 AI Agent 技能包。
