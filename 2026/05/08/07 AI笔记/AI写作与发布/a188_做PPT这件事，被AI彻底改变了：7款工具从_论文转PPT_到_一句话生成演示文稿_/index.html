做PPT这件事，被AI彻底改变了：7款工具从"论文转PPT"到"一句话生成演示文稿"

做PPT这件事，被AI彻底改变了：7款工具从”论文转PPT”到”一句话生成演示文稿”

做PPT，大概是职场人最不想做但又不得不做的工作之一。

从零开始排版、调整配色、找配图……一个10页的汇报PPT，做起来要半天，改起来更要命。

现在，AI把这件事情彻底改变了——论文可以自动转PPT，一句话就能生成演示文稿，现有的PPT还能转成网页版直接分享。

今天介绍7款相关工具，覆盖从”把论文变成PPT”到”一句话生成完整路演PPT”的完整场景。

1. Paper2Slides：港大开源 · 论文/报告一键转PPT/海报

GitHub: https://github.com/HKUDS/Paper2Slides[1] 标签: PPT · AI工具 · 港大 · 开源

它是什么

Paper2Slides 是香港大学开源的文档转演示工具，核心能力：把论文、报告、文档一键变成专业的PPT或海报。

支持处理 PDF、Word、Excel、PowerPoint、Markdown 等多种格式，一次性上传多个文件也没问题。

有什么用

传统方式： 读论文 → 手动提炼重点 → 复制粘贴到PPT → 调整格式 → 反复修改 一套流程下来，一篇20页论文的PPT要花3-4小时。

Paper2Slides方式：

python -m paper2slides --input paper.pdf --output slides --style doraemon --length medium --fast --parallel 2

一条命令，10分钟内出完整PPT。

4步智能流水线：

  1. RAG解析 — 用RAG技术精准提取文档内容，构建可检索知识库

  2. 结构分析 — 识别文档中的图表、数据、层级结构

  3. 内容规划 — 生成优化的幻灯片布局和内容组织策略

  4. 视觉生成 — 渲染专业级演示材料

支持自定义风格： 可以用自然语言描述你想要的风格，比如：

“Studio Ghibli anime style with warm whimsical aesthetic. Use soft watercolor Morandi tones with light cream background, muted sage green and dusty pink accents.”

也可以直接用内置风格：学术风（academic）、哆啦A梦风（doraemon）。

智能断点续传： 如果中途被打断，重新运行同一命令会自动从上次进度继续，不用重头来。

支持并行生成： 加 --parallel 2 参数可以同时生成2张幻灯片，速度翻倍。

适合谁

  • 学术研究人员（论文汇报、学术分享）

  • 需要做研究报告的分析师

  • 任何需要把长文档变成演示材料的人

2. Frontend Slides：Claude Code演示文稿技能 · 13.5K stars

GitHub: https://github.com/zarazhangrui/frontend-slides[2] 预览: https://frontend-design-skills-showcase.pages.dev[3] 标签: PPT · 演示文稿 · Claude · React · 13.5K stars

它是什么

Frontend Slides 是一个 Claude Code 技能，专门用来用自然语言描述需求，AI直接生成精美的网页演示文稿。

核心特点：零依赖——生成的是单个HTML文件，内嵌CSS/JS，不需要npm、不需要构建工具、不需要任何框架。

有什么用

传统方式： 打开PowerPoint → 选择模板 → 手动添加内容 → 调整格式 → 导出 → 发现字体不对、配色不对……

Frontend Slides方式：

  1. 告诉AI你想做什么：”帮我做一个AI创业公司的融资路演PPT”

  2. AI生成3种视觉风格预览，让你选

  3. AI按你选的风格生成完整演示文稿

  4. 自动在浏览器打开预览

12种精心设计的视觉风格：

  • Bold Signal — 自信、高impact、深色卡片

  • Electric Studio — 干净专业、分屏布局

  • Creative Voltage — 活力、复古现代、电蓝+霓虹

  • Dark Botanical — 优雅、精致、暖色调

  • Notebook Tabs — 编辑感、组织感、彩色标签纸张

  • Pastel Geometry — 友好、易接近、竖向胶囊

  • Neon Cyber — 未来感、粒子背景、霓虹光晕

  • Terminal Green — 开发者风格、黑客美学

  • Swiss Modern — 极简、博豪斯风格、几何

  • Paper & Ink — 文学感、首字母下沉、引文块

  • ……

支持PPT文件转换： 上传现有的PPT文件 → AI提取所有文字、图片、备注 → 选择风格 → 生成网页版演示文稿

分享和导出：

  • 一条命令部署到Vercel，获得永久分享链接（支持手机/平板/电脑）

  • 一条命令导出为PDF（适合邮件、打印）

适合谁

  • 没有设计背景但需要做演示的创业者/产品经理

  • 程序员想用代码方式做演示

  • 想让PPT有网页动画效果的人

3. oh-my-ppt：本地优先AI PPT生成器 · 不依赖云

GitHub: https://github.com/arcsin1/oh-my-ppt[4] 标签: PPT · 本地优先 · 桌面应用 · AI生成 · 无云锁定

它是什么

oh-my-ppt 是一款本地优先的AI PPT生成和编辑工具，有桌面应用版本，核心特点：所有数据都存在本地，不上传到云端，适合对数据隐私敏感的用户。

有什么用

一句话生成PPT： 输入主题和需求 → AI自动规划大纲 + 配色 + 排版 → 直接出完整PPT

支持多种输入方式：

  • 📝 直接输入主题描述

  • 📄 上传txt/md/csv/docx文档 → AI解析后生成PPT

  • 📥 导入现有PPTX文件 → 在应用内转换为可编辑的HTML页面

内置30+风格Skill： 极简白、赛博霓虹、包豪斯、日式简约、小红书白……也可以自定义风格。

对话式精准修改： 不需要重做！可以直接说：

  • “标题换个颜色”

  • “加个数据图表”

  • “第三页加个动画效果”

动画支持： 内置Anime.js v4动画引擎，支持页面切换动画和元素入场动画，适合做”演示”而不是”静态展示”。

支持本地Ollama模型： 如果想完全离线使用，可以配置本地Ollama，用自己的本地LLM来生成内容。推荐14B以上的模型。

多格式导出：

  • PDF：适合分享、归档

  • PNG：批量导出所有页面图片，适合插入公众号/Notion

  • PPTX：导出为可编辑的PowerPoint文件

适合谁

  • 对数据隐私有要求（不想上传到云端）

  • 需要经常做PPT的职场人

  • 想要”对话式修改”而不是反复重做

4. html-ppt-skill：HTML PPT制作工具 · 可作为AI Agent Skill

GitHub: https://github.com/lewislulu/html-ppt-skill[5] 标签: PPT · HTML · AI技能

它是什么

html-ppt-skill 是一个用HTML制作PPT的AI技能，可以用在各种AI编程工具中。它的核心思路：PPT不是用拖拽做的，是用HTML/CSS写的。

有什么用

  • 生成单个HTML文件PPT，浏览器直接打开就能演示

  • 支持作为AI Agent Skill使用，嵌入到各种AI编程工作流

  • 代码简洁，易于自定义

适合谁

  • 程序员背景的用户

  • 想用代码方式制作和控制PPT的人

5. open-slide：面向AI Agent的幻灯片框架

GitHub: https://github.com/AI-Meet/open-slide[6] 标签: 幻灯片 · React · AI原生 · Agent · PPT

它是什么

open-slide 是一个AI原生的幻灯片框架，核心理念：用自然语言描述需求，Agent直接写React代码生成演示文稿。

有什么用

传统做PPT：打开软件 → 选择模板 → 拖拽元素 → 调整格式

open-slide方式：告诉AI你想要什么 → AI写React代码 → 生成可交互的演示文稿

彻底摆脱传统PPT拖拽限制，用代码的精确性做演示文稿。

适合谁

  • 有React基础的用户

  • 想做可交互、动态演示的人

6. BaizeAI/talks：技术演讲幻灯片分享社区

GitHub: https://github.com/BaizeAI/talks[7] 官网: https://baizeai.github.io/talks/[8] 标签: 幻灯片 · 技术演讲 · PPT

它是什么

BaizeAI/talks 是一个技术演讲幻灯片的分享社区，收集了大量优质的技术大会分享PPT，供学习和参考。

有什么用

  • 观看和学习优质技术演讲的幻灯片

  • 了解技术圈最新动态和趋势

  • 寻找演示设计的参考灵感

适合谁

  • 想学习优质PPT设计的人

  • 技术从业者想了解行业动态

7. Flipbook：AI Agent翻页动画书 · MCP驱动 · X上很火

GitHub: https://github.com/jonradoff/flipbook[9] 标签: Flipbook · MCP · AI动画 · X热门

它是什么

Flipbook 是一款基于MCP（Model Context Protocol）驱动的AI翻页动画书工具，最近在X（Twitter）上很火。

有什么用

通过MCP协议，AI Agent可以创建精美的翻页动画书效果，适合做：

  • 产品演示

  • 故事叙述

  • 教学内容的可视化展示

适合谁

  • 想做有创意的演示效果

  • MCP生态的用户

总结：如何选择

场景 推荐工具
把论文/报告转成PPT Paper2Slides（港大开源）
一句话生成精美演示文稿 Frontend Slides（Claude Code）
本地优先、不想上传云端 oh-my-ppt（桌面应用）
用代码方式做PPT html-ppt-skill / open-slide
学习优质技术演讲设计 BaizeAI/talks
创意翻页动画效果 Flipbook（MCP驱动）

这7款工具覆盖了从”把现成文档变PPT”到”一句话生成完整演示文稿”的全场景。做PPT这件事，终于可以交给AI了。
