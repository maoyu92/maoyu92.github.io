TagLauncher：标签式文件管理工具让你的文件不再"找不到"

TagLauncher：标签式文件管理工具让你的文件不再”找不到”

你的文件是怎么组织的？

大多数人的答案是：按文件夹。一个项目一个文件夹，文件夹套子文件夹，子文件夹再套子子文件夹……

结果呢？

  • 想找”上个月那个PPT”——在3个文件夹里翻了半天

  • 一个文件属于多个项目——复制粘贴，版本混乱

  • 同一个内容多个标签——文件夹根本解决不了

标签式文件管理才是更符合人类思维的方式：一个文件可以同时有多个标签，不再被文件夹的单一层级限制。

今天介绍的 TagLauncher 就是这样一款工具。

TagLauncher：Tauri + React + TypeScript + Rust + SQLite

GitHub: https://github.com/KatouRyuuji/TagLauncher[1] 标签: 文件管理 · Tauri · React · 桌面应用

它是什么

TagLauncher 是一款基于 Tauri 2 + React + TypeScript + Rust + SQLite 的 Windows 桌面标签式启动器与本地对象管理工具。

它的核心理念：用「标签 + 文件柜 + 收藏」来组织本地文件，不再被文件夹的单一条理限制。

核心功能

对象管理：

  • 添加文件、文件夹、脚本、程序、图片

  • 支持批量导入

  • 一键启动对象

  • 一键打开所在文件夹

标签系统：

  • 支持标签的增删改查

  • 多标签交集筛选：只想看同时有”工作”和”重要”标签的文件？没问题

  • 拖拽打标

  • 对象内标签重排

文件柜归类：

  • 类似”项目”的分类概念

  • 一个对象可加入多个文件柜

  • 拖拽归档和移出

收藏夹：

  • 收藏的对象置顶展示

  • 作为内置快捷集合

搜索增强：

  • 三种模式：全部/名称/标签

  • 支持拼音匹配

  • 支持同义词扩展

  • 支持表达式语法

  • 150ms防抖

主题系统：

  • 内置多套主题

  • 支持自定义JSON主题

  • 支持Mod主题

  • 主题导入/导出

扩展系统：

  • 支持CSS、CSS+JS、Theme Mod

  • 提供完整的插件API

技术架构

层级 技术
前端 React 19, TypeScript, Zustand, pinyin-pro, Tailwind CSS
桌面容器 Tauri 2
后端 Rust, rusqlite (bundled SQLite)
构建工具 Vite, TypeScript, Tauri CLI

适合谁

  • Windows用户需要更高效的文件管理

  • 讨厌文件夹层级限制的人

  • 需要多标签组织文件的场景

  • 程序员需要一个好用的本地文件启动器

总结

TagLauncher 代表了一种更现代的文件管理思路——从”文件夹”升级到”标签”。

当一个文件可以同时属于多个标签，文件管理就不再是”放哪里”的问题，而是”它是什么”的问题。

如果你经常遇到”这个文件到底放哪个文件夹”的困扰，标签式管理值得一试。
