18k Star！DeepSeek-TUI：终端里的AI编程神器，Claude Code最强平替

18k Star！DeepSeek-TUI：终端里的AI编程神器，Claude Code最强平替

“

一个个人开发者用 Rust 打造的终端 AI 编程 Agent，登顶 GitHub Trending，被 DeepSeek 官方收录进生态。

为什么值得关注？

2026年5月，一个叫 DeepSeek-TUI 的项目突然爆了。

Star 数突破 18k，登顶 GitHub Trending 热榜，被 DeepSeek 官方收录进 awesome-deepseek-agent 生态。

它是什么？一句话：DeepSeek 版的 Claude Code。

但跟 Claude Code 不同的是——它完全开源（MIT 协议），用 Rust 写的，跑在终端里，深度适配 DeepSeek V4 模型，而且成本极低（实测单次开发不到 10 元）。

核心功能一览

🖥️ 终端内全流程编程

不需要 IDE 插件，不需要浏览器，一个终端搞定一切：

  • 读写文件、执行 Shell 命令

  • Git 管理、代码重构

  • 项目整体分析

  • Web 搜索和浏览

🧠 吃满 100 万 Token 上下文

DeepSeek V4 支持 100 万 Token 上下文窗口（约 75 万字），DeepSeek-TUI 直接吃满。

这意味着你可以一次性读取中型项目的全量源码，不用反复切换上下文。

⚡ 实时推理可视化

这是最酷的功能之一——它会流式展示模型的 Thinking-mode 思考过程。

不是黑盒输出，你能看到 AI 是怎么一步步推理的。这对调试和理解 AI 的决策过程非常有帮助。

🤖 多 Agent 并行

支持编排子 Agent 分工协作，可以并行处理多个任务。比如同时重构多个模块，或者一个 Agent 写代码、另一个 Agent 写测试。

🔒 安全可控

  • API Key 本地存储

  • 支持私有化部署

  • 可配置代码脱敏

  • 三种安全模式：Plan（只读）、Agent（交互审批）、YOLO（自动批准）

三种模式，按需选择

模式 说明 适用场景
Plan 只读探索 理解代码库、分析架构
Agent 交互式，需要审批 日常开发，安全可控
YOLO 自动批准 信任度高的任务，效率优先

Auto 模式：让 AI 自己选模型

deepseek --model auto

Auto 模式会根据你的请求自动选择：

  • 模型：简单任务用 deepseek-v4-flash（快+便宜），复杂任务用 deepseek-v4-pro（强+贵）

  • 推理等级：off / high / max

它先用一个轻量级的 Flash 路由调用来分析你的请求，然后选择最合适的模型和推理等级。短对话保持 Flash + 关闭推理，编程/调试/架构审查则升级到 Pro + 高推理。

安装超简单

方式一：npm 一键安装（推荐）

npm install -g deepseek-tui deepseek --version

国内加速：

npm install -g deepseek-tui --registry=https://registry.npmmirror.com

方式二：Rust Cargo 安装

cargo install deepseek-tui-cli --locked cargo install deepseek-tui --locked

方式三：Homebrew（macOS）

brew tap Hmbown/deepseek-tui brew install deepseek-tui

方式四：Docker

docker run --rm -it \   -e DEEPSEEK_API_KEY \   -v "$PWD:/workspace" \   ghcr.io/hmbown/deepseek-tui:latest

方式五：直接下载

从 GitHub Releases[1] 下载预编译包，支持：

  • Linux x64 / ARM64

  • macOS x64 / ARM64

  • Windows x64

国内可走阿里云/腾讯云 OSS 镜像加速。

首次使用

# 1. 设置 API Key deepseek auth set --provider deepseek # 2. 检查环境 deepseek doctor # 3. 启动！ deepseek --model auto

API Key 从 DeepSeek 平台[2] 获取，保存在 ~/.deepseek/config.toml。

更多亮点

  • Session 保存/恢复：长时间任务可以断点续传

  • 工作区回滚：side-git 快照，一键恢复到任意回合前的状态

  • 持久化任务队列：后台任务重启后不丢失

  • HTTP/SSE API：deepseek serve --http 支持无头 Agent 工作流

  • MCP 协议：连接 Model Context Protocol 服务器扩展工具

  • LSP 诊断：编辑后自动获取 rust-analyzer、pyright、gopls 等语言服务器的诊断信息

  • 实时成本追踪：每轮和每个会话的 Token 用量和费用估算

  • Skills 系统：可组合、可安装的指令包，从 GitHub 加载，无需后端服务

  • 多语言界面：自动检测，支持中文、英文、日文、葡萄牙文

成本实测

DeepSeek V4 的 API 价格本身就很低，加上 DeepSeek-TUI 的 prefix-cache 优化，实测单次完整开发会话不到 10 元。

相比 Claude Code 每月 $20 的订阅费，这个成本几乎可以忽略不计。

作者是谁？

Hunter Bown（Hmbown），独立开发者。

这不是 DeepSeek 官方出品，而是社区驱动的开源项目。但质量之高，被 DeepSeek 官方主动收录进生态。

适合谁？

  • 终端党：习惯在终端里完成一切的开发者

  • 远程开发：SSH 到服务器，不想装 IDE

  • 预算敏感：想要 Claude Code 级别的体验，但不想付订阅费

  • 深度 DeepSeek 用户：想充分利用 DeepSeek V4 的 100 万上下文

  • 开源爱好者：喜欢可定制、可扩展的工具

总结

DeepSeek-TUI 不是又一个 AI 编程玩具。它是一个真正可用的终端编程 Agent，Rust 编写，性能优秀，功能完整，而且完全免费开源。

如果你用 DeepSeek，或者想找一个 Claude Code 的平替，强烈推荐试试。

项目地址：https://github.com/Hmbown/DeepSeek-TUI\[3\]

npm install -g deepseek-tui deepseek --model auto

两行命令，开始体验。
