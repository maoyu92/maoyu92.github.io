小米发布MiMo Code：免费AI编程助手，百万上下文+终端全屏，开发者冲

小米MiMo团队在6月10日悄悄上线了一个大杀器——MiMo Code V0.1，一款终端AI编程助手，基于OpenCode构建，MIT协议开源，最关键的是：大模型限时免费用。

这不是又一个套壳CLI。它配备MiMo V2.5多模态模型，拥有百万token上下文窗口，支持TUI全屏交互、Web UI浏览器界面、非交互脚本三种模式，开箱即用。

它能干什么？

一句话：在终端里给你一个AI编程搭档。

你可以像跟ChatGPT对话一样，在终端里跟它说”帮我写个FastAPI接口”、”重构这个模块”、”跑一下测试看看哪里挂了”，它会直接读你的代码、搜索项目、编辑文件、执行命令，全自动完成。

三种模式，总有一个适合你

TUI交互模式：终端里的全屏IDE

mimo-code

启动后是一个现代化的全屏终端界面，顶部显示当前模型、模式、Git分支和上下文用量，中间是对话流，底部是输入框。

支持Tab键自动补全命令、Ctrl+R搜索历史、Shift+Tab切换Plan/Agent/YOLO三种模式：

  • Plan模式（蓝色边框）：只读分析，不动代码

  • Agent模式（青色边框）：正常开发，需要确认

  • YOLO模式（红色边框）：全自动，不问直接干

Web UI模式：浏览器里的编程助手

mimo-code webui

打开http://localhost:4280，三栏布局——左侧会话列表、中间消息流、右侧编辑器。支持流式输出、工具调用可视化、审批流程，体验类似Cursor但完全在浏览器里。

非交互模式：脚本自动化利器

mimo-code run "给所有API接口加上单元测试" --no-tui

直接传入任务，适合CI/CD集成和批量处理。

核心能力：不只是聊天

MiMo Code内置6个核心工具：

工具 作用
list_files 列出目录结构
read_file 读取代码文件
write_file 创建/写入文件
edit_file 精确文本替换（自动生成diff）
search_text 正则搜索整个项目
run_shell 执行Shell命令

此外还支持MCP工具集成、Skills自定义技能和Hooks钩子，可以扩展任意外部能力。

技术亮点：计算、记忆、进化

MiMo Code围绕三个核心主题设计：

无限上下文：通过无损压缩技术，即使是百万行项目也能保持每个关键细节完好无损。Token Plan用户默认支持1M上下文，按量付费用户256K。

代理-模型协同：专为MiMo深度优化的代理框架，包含完整的测试、审查和验证闭环。不是简单套一层壳，而是从底层对齐了Agent的工作流。

组合模式：规范→计划→构建→报告，先设计后编码，符合工程实践。

支持哪些模型？

模型 多模态 适用场景
mimo-v2.5-pro ❌ 最强编码能力
mimo-v2.5 ✅ 编码+图片/视频/音频理解
mimo-v2-pro ❌ 通用任务
mimo-v2-omni ✅ 多模态全能
mimo-v2-flash ❌ 轻量快速

在TUI里直接用@path引用图片、视频或音频文件，多模态模型会自动识别。

价格：真的免费？

限时免费——这是MiMo Code最大的杀手锏。

按量付费价格（不免费时）：

  • Pro系列（mimo-v2.5-pro）：输入¥7/百万token，输出¥21/百万token

  • 标准版（mimo-v2.5）：输入¥2.8/百万token，输出¥14/百万token

  • 缓存写入免费，重复查询自动加速省钱

Token Plan模式下，Pro模型消耗2倍token额度，标准版1倍。

对比Claude Code（Sonnet 4输入百万，输出15/百万token）和Cursor（$20/月），MiMo Code在免费期间几乎没有成本门槛。

MiMo Code的差异化在于：终端原生+百万上下文+多模态+免费。对于习惯终端工作流的开发者来说，这是一个不需要切换IDE就能用的AI助手。

怎么装？

一行命令：

npm i -g @xiaomi-mimo/cli

然后配置API Key：

mimo-code settings

或者直接编辑~/.mimo-code/config.json：

{ "apiKey": "你的API Key", "baseUrl": "https://token-plan-cn.xiaomimimo.com", "model": "mimo-v2.5", "temperature": 0 }

API Key在platform.xiaomimimo.com[1]注册获取。

实际体验如何？

基于OpenCode构建，MiMo Code的TUI体验相当流畅。流式输出、工具调用可视化、diff着色、审批流程这些该有的都有。

百万上下文是真正的杀手级特性——处理大型项目时不需要手动截断上下文，Agent能”看到”整个代码库，这对于跨文件重构、理解复杂依赖关系非常有用。

不跟你卷IDE插件，直接在终端里给你一个完整的AI编程Agent。对于每天泡在终端里的开发者来说，这是一个”装了不亏、试试不要钱”的工具。

限时免费期间，建议所有开发者都去试试。毕竟，免费的才是最贵的——但这次，免费可能真的就是免费的。
