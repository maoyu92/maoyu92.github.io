139个AI科研技能包：从文献调研到论文投稿的全流程武器库

写论文还在一个字一个字地憋？有一套开源工具，能让 AI 帮你完成从文献调研到论文投稿的全流程——139 个技能，覆盖生物信息、化学信息、临床研究、地理空间等几乎所有学科。

一、科研人的痛点：流程太长，工具太散

做科研的人都知道，一篇论文的诞生要经历多少环节：

文献调研 → 选题 → 大纲 → 撰写 → 修改 → 同行评审 → 格式调整 → 投稿

每个环节都有对应的工具，但这些工具彼此割裂。你用 Semantic Scholar 找文献，用 Zotero 管理引用，用 LaTeX 排版，用 Grammarly 检查语法，用 Overleaf 协作……光是工具切换就要消耗大量精力。

最近，GitHub 上出现了两个项目，试图用 AI Agent 技能包的方式，把这个全流程串起来：

  • academic-shcolar-skills（学术研究技能包）：端到端的研究到论文工作流

  • academic-skills（学术技能集合）：139 个覆盖各学科的 Agent 技能

二、项目一：academic-shcolar-skills（端到端研究工作流）

2.1 核心定位

这是一个研究到论文的全流程工作流套件，专为 AI 编程 Agent 设计。

它不是简单的”帮你写论文”，而是把科研流程拆解成了 10 个阶段，每个阶段都有专门的 Agent 团队负责。

2.2 四大核心模块

① Deep Research（深度调研）—— 13 人研究团队

这不是一个简单的搜索工具，而是一个由 13 个 Agent 组成的虚拟研究团队：

  • 苏格拉底式引导模式（逐步追问，不直接给答案）

  • PRISMA 系统性综述支持

  • 意图检测（理解你真正想问什么）

  • 对话健康监控（防止跑偏）

  • 跨模型交叉验证（可选）

  • Semantic Scholar API 文献验证

② Academic Paper（学术论文）—— 12 人写作团队

从大纲到成稿的完整写作支持：

  • 风格校准（适配不同期刊/会议的写作风格）

  • 写作质量检查

  • LaTeX 格式加固

  • 可视化图表生成

  • 修改教练（逐句反馈）

  • 引用格式转换

  • 防泄露协议（防止 AI 痕迹被检测）

③ Academic Paper Reviewer（论文评审）—— 7 人评审委员会

模拟同行评审的多视角审查：

  • 主编（EIC）+ 3 个动态审稿人 + 魔鬼代言人

  • 0-100 分质量评分

  • 让步阈值协议（什么时候该妥协）

  • 攻击强度保持（保持批评的尖锐度）

  • R&R 可追溯矩阵

④ Academic Pipeline（学术管线）—— 10 阶段编排器

把上面三个模块串联成完整流程：

10 个阶段，每个阶段都有自适应检查点、声明验证、Material Passport（材料护照），以及可选的跨模型完整性验证。

2.3 安装方式

Claude Code（推荐）：

# 在 Claude Code 中 /plugin marketplace add crazymsn/academic-shcolar-skills /plugin install academic-research-skills # 然后运行 /ars-plan

传统安装：

把四个文件夹复制到 .claude/skills/：

  • deep-research/

  • academic-paper/

  • academic-paper-reviewer/

  • academic-pipeline/

OpenCode ✅ 通过项目配置支持

三、项目二：academic-skills（139 个学科技能包）

3.1 核心定位

这是一个**学术技能的”超市”**——139 个技能目录，覆盖几乎所有学科领域。

3.2 学科覆盖

这不是几个通用技能的简单集合，而是按学科细分的专业技能库：

生命科学：

  • 生物信息学、基因组学、单细胞分析、多组学工作流

  • Biopython、Scanpy、scvi-tools、CellxGene

化学与药物：

  • 化学信息学、药物发现、分子建模、蛋白质工程

  • RDKit、Cobrapy、Benchling

数据科学与AI：

  • 科学 Python 包：scikit-learn、PyMC、NetworkX、Dask

  • 机器学习、预测、强化学习、模型解释

临床与医学：

  • 临床研究、治疗方案、法规写作、医学影像

  • 临床决策支持、临床报告

地球与空间科学：

  • 地理空间科学、遥感、材料科学、物理、天文学

  • Astropy、BIDS

学术写作：

  • 文献综述、同行评审、科学写作、海报、幻灯片

  • 引用管理、文档处理

3.3 安装方式

# 预览可用技能 npx skills add crazymsn/academic-skills --list --full-depth # 安装所有技能（Claude Code 项目级） npx skills add crazymsn/academic-skills --skill '*' --agent claude-code --copy -y --full-depth # 安装所有技能（全局） npx skills add crazymsn/academic-skills --skill '*' --agent claude-code --global --copy -y --full-depth # 安装单个技能 npx skills add crazymsn/academic-skills --skill scanpy --agent claude-code --copy -y --full-depth

3.4 安全审查

每个技能都包含 SKILL.md 文件，可能影响 AI Agent 的行为（运行命令、安装包、网络请求等）。项目提供了安全扫描工具：

# 安全扫描 uv pip install cisco-ai-skill-scanner skill-scanner scan academic-skills --use-behavioral

最佳实践：两个项目配合使用——用 academic-shcolar-skills 管理整体流程，用 academic-skills 提供特定学科的专业技能。

五、对科研工作流的影响

5.1 效率提升

  • 文献调研：从几天缩短到几小时

  • 论文撰写：从几周缩短到几天

  • 同行评审模拟：从找人帮忙缩短到即时可用

5.2 质量保障

  • 多 Agent 交叉验证减少遗漏

  • 防泄露协议降低 AI 检测风险

  • Material Passport 确保可追溯性

5.3 民主化

  • 降低科研工具的使用门槛

  • 让没有资源的团队也能获得专业级支持

  • 覆盖从本科到博士的全阶段需求

六、局限性与注意事项

  • 非商业许可：academic-shcolar-skills 使用 CC BY-NC 4.0，商业用途需注意

  • 技能安全：139 个技能中可能包含执行命令的脚本，安装前需审查

  • AI 痕迹：虽然有防泄露协议，但仍需人工润色

  • 学科深度：通用技能多，深度专业技能需要自己补充

七、结语

从 139 个学科技能到 10 阶段论文管线，这两个项目代表了 AI 辅助科研的一个新方向：不是替代研究者，而是给研究者装上”技能外挂”。

当 AI 能帮你做文献调研、写初稿、模拟评审、调整格式时，研究者可以把精力集中在真正需要人类智慧的地方——提出问题、设计实验、解读结果。

这，才是 AI 在科研中应有的角色。
