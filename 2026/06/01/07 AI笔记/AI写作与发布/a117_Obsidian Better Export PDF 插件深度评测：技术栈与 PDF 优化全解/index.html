1. 项目基本信息

Better Export PDF 是 Obsidian 生态中最受欢迎的 PDF 导出增强插件之一，与官方导出相比增加了导出预览、书签导航、页码、PDF 元数据等大量实用功能。

⚠️ 注意：网上曾有 mProjectXYZ/better-export-pdf 仓库，但该项目已停更或转移，实际活跃项目为 l1xnan/obsidian-better-export-pdf。

2. 技术栈：如何实现 PDF 导出？

2.1 核心方案：Electron 内置 API

该插件完全不依赖 Pandoc、Puppeteer 或 Playwright，而是直接调用 Electron 的 webview.printToPDF API：

这是该插件与另一款知名插件 obsidian-enhancing-export（基于 Pandoc）的根本区别。

2.2 技术依赖

  • **pdf-lib (^1.17.1)**：注入 PDF 书签、元数据

  • deepmerge：多文件合并时配置合并

  • p-limit：批量导出时的并发控制

  • Svelte 5：v2.0 版本重构了前端 UI

2.3 v2.0 渲染引擎升级

2026年4月发布的 v2.0 是一个重大架构升级：

  • v1.x：基于 WebView 模拟打印，常出现样式冲突和渲染异常

  • v2.0：直接在主页面渲染，可预览真实 PDF 效果，从根本上解决了样式兼容问题

4. 主题/样式系统

Better Export PDF 完全复用 Obsidian 的主题系统，导出效果与阅读模式一致。

5. 适用场景与局限

✅ 适合的场景

  • 技术文档、教程导出为带书签导航的 PDF

  • 需要显示页码的正式文档输出

  • 批量导出整个文件夹的笔记为 PDF

  • 通过目录文件将多个笔记合并为一个 PDF

  • 导出前预览最终 PDF 效果

❌ 局限

  • 仅限桌面端（移动端无法使用）

  • 不支持 HTML/EPUB/DOCX 等格式（仅 PDF）

  • 多文件自动合并不能保证顺序，需通过目录文件控制

6. 安装方法

方式一：社区插件市场 设置 → 第三方插件 → 社区插件市场 → 搜索 "Better Export PDF"

方式二：手动安装 从 GitHub Releases 下载 .zip，解压到 {Vault}/.obsidian/plugins/

方式三：BRAT 安装 BRAT 插件后添加仓库地址

8. 总结

Better Export PDF 是 Obsidian 生态中最成熟的 PDF 导出增强插件，v2.0 版本的架构升级解决了长期以来的样式兼容问题。对于需要将笔记输出为专业 PDF 的用户，这是几乎必装的工具。唯一需要注意的是它专注于 PDF 单一格式，如需 docx/html 等多格式输出，建议搭配 obsidian-enhancing-export（基于 Pandoc）组合使用。
